**它凭什么长这么快。** 不是因为它造了更好的模型，是因为 2026 年出现了一类**以前不存在的采购行为**：应用公司开始自己做 RL 后训练。

2025 年之前，一家公司想让 AI 干活只有两条路——调前沿 API，或者雇一队 ML 工程师从头搭训练集群。2026 年上半年，第三条路突然跑通了：拿一个开源权重的中等模型（Qwen3.5-35B、GLM、Nemotron、gpt-oss），在自己业务的那一个工作流上做 RL 后训练，就能在**那一个任务**上打赢前沿模型，并且快一截、便宜一到两个数量级。Ramp 是官方和投资人新闻稿都在用的样板：**约一周时间、不到 $5 万的训练花费**，训出一个 35B 的表格检索子 agent（FastAsk），在自己的留出测试集上 **66.25% 对 Claude Opus 4.6 的 61.88%**，延迟低约 27–30%，成本只是 Haiku 的一小部分 `[官方案例 + 创始人访谈；基准是 Ramp 自建的，没有第三方复核]`。

这条路需要一整条流水线：卡、分布式 RL 训练框架、任务环境、能跑不可信代码的沙箱、评测、再把训好的权重部署出去。前沿实验室内部都有这套车间，但**不卖**——它们卖的是 API。Prime Intellect 把这套车间整条打包成自助产品租出去了，而且每一层都单独计价、可以只买其中一层。于是 2026 年 2 月 Lab 上线、5 月 GA（beta 期跑了 10,000+ 个训练任务）`[官方]`，到 7 月客户数做到 **6,000+**，年化过亿。

但增长的真实瓶颈创始人自己说得很直白：**卡。** 公司当时约 **15,000 张 GPU，正在扩到 30,000+**，而 GPU「基本上这一年都售罄了」`[创始人访谈]`。一门由采购量而不是产品力决定上限的生意，长得快是因为它站在一条正在拓宽的管子上，而不是因为管子是它的。

## 1. 核心产品

**卖什么。** 官方把整条线叫「Open Superintelligence Stack」，实际是四类可以分开买的东西 `[官方网站，2026-10-10 抓取]`：

| 层 | 产品 | 卖法 |
|---|---|---|
| 算力 | On-Demand GPUs（1–256 卡，跨云，带 SLURM/K8s 编排与 InfiniBand）、Liquid Reserved Clusters（50+ 机房询价，外加一个把闲置卡转卖出去的现货市场） | 按卡时 |
| 后训练 | Lab：RL Environments（配 Prime CLI 与开源 `verifiers` 库）、Hosted Training（托管大规模 agentic 训练）、Hosted Evaluations（100+ 开源模型的托管基准与公开榜） | 按 token |
| 执行 | Prime Sandboxes（跑 RL 用的 MicroVM，2026-09 GA，累计约 3,000 万个沙箱） | 按 vCPU / 内存 / 磁盘 / 时长 |
| 部署 | Prime Inference（2026-10-02 对外开放，首发托管 GLM-5.3；另有把第三方模型统一成 OpenAI 兼容接口的 Inference Gateway） | 按 token |

外加三样**免费**的东西，是整条漏斗的入口：Environments Hub（2,500+ 社区贡献的 RL 环境，另有自动生成的 365,000+ 个 SWE/终端/检索环境）、开源的 `prime-rl` / `verifiers` / `prime` CLI、以及它自己训的 INTELLECT 系列模型（2024-11 的 INTELLECT-1 10B、2025-05 的 INTELLECT-2 32B、2025-11 的 INTELLECT-3 106B MoE，全部开源训练配方）。

**谁在什么场景下打开它。** 创始人给的客户构成是四类：AI 原生创业公司（Ramp、Zapier、Browserbase、Character.AI、Goodfire、Extropic、Mixedbread、Arcee）、新生实验室（neolabs）、传统企业、以及主权买家（要能在自己机房里跑整条栈）`[创始人访谈 + 官方案例页]`。打开它的那一刻通常是：**某个工作流上前沿模型不够准、或者太贵太慢，而这个工作流一天要跑几十万次。**

**Before / After。** 用 Ramp 这条线说最清楚：

- **Before**：要么继续调前沿 API（每次调用都按前沿价付钱，准确率卡在 61.88% 上不去，延迟也压不下来）；要么自己搭训练集群——签几百万美元的包年卡合约、自己写容错训练编排、自己造任务环境和奖励函数、自己搭沙箱跑模型生成的代码。后者对一家支付公司来说根本不是选项。
- **After**：在 Lab 上用自己的 14 类财务任务定义一个环境，租几千张卡跑一周，**花费不到 $5 万**，拿到一个 35B 的专用子 agent，权重归自己。架构变成「前沿大模型做编排和规划，专用小模型做执行」。

它替代的不是人，也不完全是软件 —— 它替代的是**一家公司原本必须自己攒出来的一个 ML 平台团队加一份包年算力合约**。而它创造的新需求是真的新：2025 年上半年「应用公司自己做 RL 后训练」这个采购项在大多数公司的预算表里不存在。

## 2. 商业模式

- **收费对象**：AI 公司和企业的**基础设施 / 研发预算**。掏钱的是工程和 ML 团队，不是业务部门。这一条决定了天花板：它的参照价是「客户自己建这套要花多少钱」，不是「客户能省掉多少人」—— 和抢人力预算的应用层公司差一个数量级。
- **定价结构**：**纯用量制，四种计价口径并存**，无席位、无年约（官方价，2026-10-10 抓取）：

  | 口径 | 价格 |
  |---|---|
  | GPU 按时 | B300 $4.99、B200 $3.49、**H100 SXM $2.43（现货 $0.94）**、H200 $1.99（另有 $1.80 / $1.23 / $0.47 等不同挂单）、GH200 / RTX Pro 6000 / A100 / A40 $3.14 |
  | 训练按 token | Qwen3.5-35B-A3B：输入 $0.25 / 输出 $0.75 / **训练 $1.00** 每百万 token；Qwen3.5-9B：$0.20 / $0.60 / $0.60；gpt-oss-20b：$0.10 / $0.30 / $0.40；Nemotron-3.5-30B：$0.15 / $0.45 / $0.60 |
  | 沙箱按资源 | vCPU $0.02/核·时、内存 $0.0125/GiB·时、磁盘 $0.0002/GiB·时（1 核 + 2GiB + 5GiB ≈ $0.046/时），镜像与快照存储 $0.10/GiB·月 |
  | 推理按 token | 未全量公开，逐模型在控制台里报价 |

  注意两件事：**Shared Hosted Training（LoRA）已于 2026-10-08 停止接新任务**，托管训练整体转向专属实例，全参微调仍在闭门 beta —— 产品正在从「自助小单」往「专属大单」挪。另一件：创始人说融资交割后**把价格翻了一倍** `[创始人访谈]`，所以这 $100M 里有一部分是提价而不是用量。

- **单位经济 —— 先做一道除法。** 这是看任何算力公司最值得先做的事：

  > 15,000 张卡 × 8,760 小时 = **1.31 亿卡时/年**。$100M ÷ 1.31 亿 ≈ **$0.76 / 卡时**。
  > 而它自己挂牌 H100 是 $2.43、现货 $0.94。

  也就是说：**这 1 亿年化收入几乎可以被「它手里的卡按现货价卖出去」完整解释完**，不需要假设软件卖了多少钱。`[估算，依据：创始人给出的 15,000 卡与官方 $100M 年化]` 结论很硬 —— **Lab、环境、评测、沙箱基本是免费或近免费的引流品，真正收钱的是机器**。公司从未披露收入构成、毛利率、客户集中度，也没说 gross 还是 net。
  
  毛利方向上只能给参照：2026-10-07 的成交指数把 H100 SXM 定在约 **$2.85/卡时**，而它挂 $2.43、现货 $0.94 —— 它在**低于市场指数的价位抢量**，并且因为依赖多家供应商，**算力市场明确不给 SLA**，要稳定性的客户被引导去 Secure Cloud，供应商掉链子就退款或给 credit `[媒体核对官方文档]`。这是一门靠填满别人机房的生意，毛利随现货价走。

- **它从谁的预算里抢钱**：**软件预算里最薄的那一格 —— 算力采购**。它抢的是客户原本要付给 AWS / CoreWeave / 包年合约的那笔钱，以及原本要付给前沿模型 API 的推理账单。前者是零和的价格战，后者才是它的叙事所在。

**不可替代性（必答，且必须写短）**

| 问题 | 答案 |
|---|---|
| **自己造了什么** | 容错分布式训练栈，跨洲通信量降约 400x，INTELLECT-3 是自己训出来的 |
| **转手卖什么** | GPU 卡时。15,000 卡反推均价 $0.76/卡时，收入几乎全是转售 |

**不可替代性：弱。** 真正自研、别人做不出来的那部分（跨机房容错 RL 训练栈、环境格式）被它自己全部开源了 —— 这买来了 6,000 个客户的入口，同时把切换成本清零；而它收钱的那一层（卡时）是全行业最商品化的一层，它还在用低于成交指数的价格卖。唯一在变强的资产是**算力采购合约**（15,000 → 30,000 卡，且市场售罄），但那是 neocloud 的护城河，不是软件公司的护城河，而且需要持续烧钱续约。

## 3. 北极星指标

- **North Star（推断）**：**平台上消耗掉的训练 / RL token 量（或等价的 GPU-hour 消耗）**。官方从未披露内部指标，但它整条产品线的计价单位、以及创始人把「卡售罄」当成唯一瓶颈来讲，都指向这一个数。
- **为什么是它**：它领先于收入两步。客户把一个 agent 的 RL 循环接到平台上，训练 token 消耗会在合同金额变化前先涨；反过来，客户一旦改用别家或退回调 API，token 消耗会在续费窗口前先掉。更关键的是，它同时回答了「客户是不是只在这儿租机器」—— 纯租卡的客户 token 消耗是零。
- **配套指标**：
  1. **算力采购量**（15,000 → 30,000+ 卡）：这是供给侧的硬上限，创始人自己点名的瓶颈。
  2. **机队利用率**（未披露）：反推均价 $0.76/卡时对挂牌 $2.43，这个比值就是毛利的全部。
  3. **沙箱并发与累计量**（累计约 3,000 万、仪表盘显示 20,000+ 并发）：代表客户是真在跑 agentic RL，不是在跑一次性微调。
  4. **环境数**（社区 2,500+ / 自动生成 365,000+）：免费层的漏斗宽度。

## 4. AI 在业务中的作用

| 层次 | 该公司的情况 |
|---|---|
| **AI = 产品本身** | **是，而且是少见的真自研**。它自己从零训了 INTELLECT-1/2/3（10B → 32B → 106B MoE），自己写了 PCCL、OpenDiLoCo、prime-rl、verifiers，发了「跨洲通信量降约 400x」的容错训练方法。没有 AI，它的产品连名字都不成立。 |
| **AI = 效率杠杆** | **是**。40 人做到 $100M 年化，靠的是整条栈自助化：从环境到训练到部署全是 CLI 和 API，不配实施团队。它还把自家的「自主 AI 研究」（Prime Agent、nanoGPT 自动加速、General Agent）当内部研发杠杆用。 |
| **AI = 营销标签** | **有一处名不副实值得点破**，但不在 AI 上，在「去中心化」上。种子轮是 Distributed Global 与 CoinFund 这类加密基金共同领投的，早期文档里写着部署在 Base Sepolia 测试网的 `RewardsDistributor` 合约、给算力池发代币奖励、「未来迁移到自研链」—— 这些表述在 2025 年初那轮主流 VC 融资之后被删掉了 `[媒体]`。分布式训练的技术是真的，但「贡献算力换模型所有权」的那套协议叙事没有变成收入。 |

**自研还是调 API。** 训练侧完全自研；推理侧卖的是别人的开源权重（首发托管 GLM-5.3，另做第三方模型的统一网关）。所以它的模型层依赖风险很特殊 —— **不依赖任何一家闭源 API，但完全依赖「还有人在发好的开源权重」**。创始人自己把这当成需要警惕的事：他点名 Moonshot 改许可证、往闭源收，并把希望寄在美国的开源发布（poolside 开了权重、新生实验室会跟上）和 NVIDIA 的 Nemotron 联盟上 —— 它是该联盟成员，这也是它拿 NVIDIA 投资的原因之一。

**基础模型升级是利好还是威胁 —— 两面都真。** 开源权重每升一级，它的原料变好、后训练需求变多，是**利好**；闭源前沿模型每降一次价、每提一次准确率，「自己训一个专用小模型」的理由就薄一层，是**威胁**。它赖以存在的东西不是模型能力，是**开源权重和前沿 API 之间的那一到两个数量级价差**。这个价差由两拨与它无关的人决定。

## 5. 增长引擎

主引擎是**开源做漏斗 + 自助转化**，不是销售：

1. **开源与研究声量是最上层的入口**。prime-rl、verifiers、PCCL、INTELLECT 系列模型全部开源，Environments Hub 免费放 2,500+ 个社区环境和 365,000+ 个自动生成环境。做 RL 的人想开工，第一个 `pip install` 大概率装到它的库，而那个库最顺手的后端就是它的平台。这是典型 PLG：6,000 客户、反推客单价约 $1.67 万/年，这个形状只能是自助注册，不可能是销售打下来的。
2. **案例博客当销售材料**。Ramp、Zapier、Goodfire、Extropic、Mixedbread、Browserbase 的案例全部写成技术文、带可复现细节，由客户的工程负责人出面背书（Ramp 的联席 CEO 直接给引语）。它卖给工程师，所以用工程师的语言卖。
3. **上游绑定做渠道**。加入 NVIDIA Nemotron 联盟并在 Lab 上做 Nemotron 3 的后训练，拿 NVIDIA / Intel / Dell 三家战略投资 —— 既是算力货源，也是企业与主权客户的介绍人。
4. **真正的 GTM 转折点在 2025 年 10 月**：请了一位 Head of Applied GTM，此后约 9 个月收入从接近零做到 $100M+ `[媒体 + 第三方]`。换句话说，技术在 2024 年就有了，钱是从 2025 年底才开始进来的 —— 这一条比任何「开源飞轮」的说法都更能解释曲线。

## 6. 风险与争议

1. **这 $100M 的口径值得打折，而且公司自己给了打折的理由。** 「annualized」是把近期月度或季度收入乘出来的，用量计费没有年约、没有自动续费；创始人另外说过**融资交割后把价格翻了一倍**，所以这个数里有多少是提价、多少是用量，外部无从拆分。公司从未发布审计财报、月度收入、收入构成或客户集中度。6,000 客户 ÷ $100M ≈ 客单价 $1.67 万/年，说明长尾是自助租卡的小客户 —— 这类收入对价格极度敏感，别家降价就走。
2. **毛利可能比估值倍数暗示的还薄，而市场已经定价了这件事。** 10x 收入倍数在 2026 年的 AI 一级市场里属于低位（应用层同期 25–67x），差距正是「机器收入 vs 软件收入」的折价。它不自有机房、靠 50+ 家供应商拼机队、明确不给算力 SLA，而且挂牌价低于成交指数 —— 这是在用价格抢量。一旦 GPU 现货价下行，收入和毛利同向压缩。
3. **上游原生做这件事，它剩下的只有一句话。** Thinking Machines 的 Tinker 已经是公开定价的后训练 API（并在 2026-07 涨了价），OpenAI 有 RFT，Together、Fireworks 也在卖 RL 微调；反方向上 Modal、Baseten 在沙箱和推理侧往回打。等所有人都能一键 RL 微调时，它剩下的差异化只有「权重归你、可私有部署、可主权化」—— 这是一句真话，但它是**合规和采购偏好**，不是技术护城河。
4. **自研的部分被自己送光了。** 真正难做、别人短期做不出来的东西（跨机房容错训练、环境与评测格式）全部开源。好处是 6,000 客户的入口；代价是切换成本约等于「重写几周编排代码」。开源拿增长可以，当护城河不行。
5. **增长上限不在自己手里。** 创始人说卡「这一年基本售罄」，公司从 15,000 张扩到 30,000+ 张。粗算 30,000 张卡一年的租金量级就远超它刚融到的 $130M，所以它只能继续做过手生意 —— 拿不到卡就长不动，和产品好坏无关。
6. **加密出身的叙事折价。** 种子轮由加密基金共同领投，早期文档含代币奖励合约，后被删除。看空的问法很干净：如果「去中心化训练 + 贡献者持有模型所有权」是真护城河，为什么要把它拿掉？如果不是，那剩下的就是一家开源做市场的 neocloud。
7. **案例全是客户自评。** Ramp 的 66.25% vs 61.88%、27–30% 的延迟优势、「只是 Haiku 成本的一小部分」，基准和评分标准都由合作双方自己定，没有第三方复核。它的 Hosted Evaluations 还同时在给 100+ 开源模型做公开榜 —— 既当裁判又当卖家的那个结构性问题（本档 Arena、Snorkel AI 两篇里出现过）在这里也有，只是规模还小。

## 7. 给我的启发

1. **看任何算力相关的公司，先做一道除法：卡数 × 8,760 ÷ 年化收入。** Prime Intellect 这道题算出来是 $0.76/卡时，而它自己挂牌 H100 $2.43、现货 $0.94 —— 一个除法就判定了「这 1 亿是软件钱还是机器钱」，也顺带判定了 10x 而不是 40x 倍数的合理性。公司不披露收入构成时，物理量会替它披露。
2. **开源可以是最好的漏斗，但它和护城河是互斥的。** 它把 prime-rl、verifiers、环境、训练配方全部送出去，换来 6,000 个自助客户的入口；同一个动作把客户的迁移成本降到「几周工时」。所以判断一家开源驱动的公司，不要问「社区多大」，要问「收钱的那一层是什么」—— 这里收钱的那一层恰好是全行业最商品化的一层。
3. **有些生意的命运绑在一个与它无关的价差上。** 「自己训一个专用小模型」之所以成立，全靠开源权重和前沿 API 之间的一到两个数量级价差；Ramp 花不到 $5 万换掉前沿调用，这笔账成立的前提由中美各家实验室的开源政策和前沿定价决定。看这类公司时，与其研究它的产品路线图，不如先问：**我赖以存在的那个价差，是谁在维持、会不会收窄。** 答案是「别人」和「会」的时候，再快的增速也只是在一个限期内有效。
