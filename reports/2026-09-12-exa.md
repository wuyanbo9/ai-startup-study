**它凭什么长这么快？**

一句话：**它赌的是「搜索的用户从人变成了机器」，而且赌得比所有人都早、也比所有人都重**。

2023 年之前，全世界的网页检索接口只有两种：Google/Bing 的官方 API（给人用的十条蓝链），和一堆抓取 Google 结果再转卖的中间商（SerpAPI、Serper、Bright Data）。这两种的产物都是同一个东西——**一页给人看的摘要**。而一个 coding agent 要的完全不是这个：它要的是「跟这段报错语义相近的三十个 GitHub issue 的正文」，要的是去掉导航栏和 cookie 提示的纯净正文，要的是 200 毫秒内返回、因为它一次任务里要搜二十次。

Exa 的选择是**不套壳**。它自己写爬虫（现在跟踪 500B+ URL）、自己训 embedding 模型（在自购的 GPU 集群上，Sacra 记录为 80 张 A100 加 144 张 H200）、自己写向量数据库，用「下一个链接预测」做语义召回而不是关键词匹配 `[官方/估算]`。这在 2022 年看起来是个愚蠢的决定——重造一个索引，烧钱、慢、且 Google 已经有了。

但 2025 年发生了一件事：**Cursor、Cognition 这批编码 agent 起量了**。检索调用量从此不再按「有多少人在搜」增长，而是按「有多少 agent 任务 × 每个任务搜多少次」增长。Bryk 自己的说法是，Series C 前半年 Exa 在代码检索上还打不过 Google，半年后「几乎每个编码 agent 都在用我们」`[官方]`。收入曲线就是在 2025 年这一段折向上的——从 $1.86M（2024 年底）到 $10M（2025-09），九个月 5 倍。

同一时期的第二个证据不在收入表里，在价格表里：**2026-03，Exa 把标准搜索从 $5/1k 涨到 $7/1k** `[媒体]`。在一个有 Parallel 卖 $1/1k、fastCRW 卖 $1.38/1k、Bright Data 便宜 5–7 倍的市场里涨价 40%，这比任何第三方 ARR 估算都更能说明它在客户那里的位置。

## 1. 核心产品

**卖的是一次 HTTP 请求，买家是一段代码。**

Exa 没有面向人的产品界面（早期有过，现在的重心全在 API）。它的调用方是 agent：Cursor 写代码时要查文档，Devin（Cognition）要读网页，HubSpot 用它做客户信息丰富化（官方口径 270 万次 enrichment），Monday.com、OpenRouter、Notion AI 都在用 `[官方]`。

产品线（价格见下节）：

- **Search / Deep Search**：语义检索自有索引，返回 URL 与元数据。deep / deep-reasoning 档会把一个查询扩成多个变体并行跑
- **Contents / Highlights**：把页面正文抽出来。官方说 Highlights 能把喂给 LLM 的 token 量**压掉 20 倍以上** `[官方]`——这是给 agent 省钱的那一刀
- **Agent API**：按「努力程度」一口价（minimal 到 xhigh），Exa 自己跑多轮检索再返回结论
- **Websets**：持续跑的结构化查询（找人、找公司），官方称已有 10 亿+ 人物档案、7000 万公司实体 `[官方，2026-03]`
- **Monitors**：网页变更监控

**Before / After：**

| | 原来 | 现在 |
|---|---|---|
| 给 agent 加联网 | 调 SerpAPI 拿 Google 十条蓝链 → 自己写爬虫抓正文 → 自己清洗 HTML → 截断喂给模型 | 一个 `/search` + 一个 `/contents`，返回的就是已清洗、已按语义排序、已压缩的正文片段 |
| 召回方式 | 关键词匹配，query 写不对就搜不到 | 语义召回，「跟这个东西相似的页面」是一等公民（`find similar` 是它最早的卖点） |
| 延迟 | 抓取+清洗动辄数秒 | 180ms–1s，Instant 档 <200ms |
| 成本 | 按页抓取 + 全文喂模型的 token 费 | $7/1k 次检索 + $1/1k 页正文，token 量被压掉 20x |

它替代的**不是人**，是**每个 AI 公司内部那个「联网模块」的工程小组**——过去每家都要自己搭一套抓取加清洗的流水线，现在变成一行 API。这是典型的「替代软件预算（而且是自建成本）」，不是「替代人力预算」。这一点决定了它的天花板，后面会说。

| 问题 | 答 |

| **自己造了什么** | 自建爬虫（500B+ URL）、自训 embedding 与向量库、自购 GPU 集群。不是套壳 |

理由：**资产是真的，锁定是假的**。左边三格答得比本档任何一家都实——抽掉 AI 叙事，剩下的是一个真实存在、每周处理 25 万亿 token 的网页索引，这在本系列里只有 Baseten 的多云调度能比，而 Baseten 还是转售 GPU。但右边两格很薄：客户走的是按次计费、无合同锁定、无数据沉淀，换成 Parallel 只要改几行代码；而 OpenAI 和 Anthropic 已经把 web search 内置进了自家 API。它的位置完全由**索引质量的领先窗口**支撑，不由任何切换成本支撑——这个判断在 2026-03 那次涨价里得到了正面验证，也会在领先窗口关闭的那天原样失效。

## 3. 北极星指标

- **North Star（推断）**：**每次 agent 任务的检索调用数 × 活跃 agent 任务数**——也就是官方唯一愿意披露的那个量：**Highlights 每周处理的 token 量（25 万亿）**。公司对外从不报收入，却报这个数，本身就是信号。
- **为什么是它**：Exa 的收入 = 调用量 × 单价，且**没有席位、没有订阅底价**，所以收入是调用量的纯滞后函数。一个客户的 agent 产品起量，Exa 的账单下个月自动涨；反过来客户优化掉几次检索，收入立刻掉。调用量领先收入约一个计费周期。
- **配套指标（推断）**：
  1. **检索质量评测胜率**——它自己发了 WebCode（编码 agent 检索评测，2026-03）和学术检索 SOTA（2026-07）两套基准，且在 C 轮里拿「打赢 Perplexity 64.8% vs 60.1%」说事 `[官方]`。对一家没有切换成本的公司，评测胜率就是续费率。
  2. **被设为默认检索源的 agent 数量**——Bryk 的原话「几乎每个编码 agent 都在用我们」就是这个指标的口语版。
  3. **付费客户数 / 开发者数的转化**（40 万开发者 vs 5,000 家公司客户，约 1.3%）——免费额度每月 $10，这个比例是它 PLG 漏斗的真实效率。
- 以上全部为推断，公司未披露任何内部指标口径。

## 4. AI 在业务中的作用

| 层次 | Exa 的情况 |
|---|---|
| **AI = 产品本身** | **是，而且是罕见的「自研模型即产品」**。它的召回靠自训 embedding 模型、正文抽取靠自训 Highlights 模型，都跑在自购 GPU 上。没有这两个模型，它就只是一个爬虫。 |
| **AI = 效率杠杆** | 弱。110 人做 $12M，人均 $109K，**低于传统 SaaS**。它不是「小团队用 AI 做大生意」的样本，恰恰相反：人头全砸在造基础设施上（新招的是前 Meta 检索基建负责人、前 Yandex 搜索后端负责人、Google 研究团队成员）。 |
| **AI = 营销标签** | 几乎没有。它是本系列里少数几家「实际做的比讲的多」的公司——官方博客发的是评测集和数据框架（exa-d、WebCode），不是愿景。 |

**自研还是调 API**：核心检索链路（爬取、embedding、向量召回、正文抽取）**全部自研自训**，这是它和 Tavily、Serper、SerpAPI 这类中间商的分水岭。只有 Answer 和 Agent 两个端点需要外部 LLM 做生成与规划，**外购比例未公开**。模型层依赖风险因此比本档大多数公司低——**它不怕模型涨价，它怕模型自带功能**。

**基础模型每次升级，是利好还是威胁**：
- **利好的部分**：模型越强、agent 跑得越久，一次任务里的检索次数就越多。Exa 按次收费，这是纯增量。B 轮到 C 轮之间收入的斜率，本质上是被上游模型的 agent 能力推上去的。
- **威胁的部分**：模型厂每次升级都在往自家 API 里塞更多自带工具。OpenAI 和 Anthropic 的内置 web search 已经是 $10/1k 的现货商品，且对客户是零集成成本。Exa 的全部依仗是「内置那个搜得没我准」——这是个**质量差**，不是**结构差**，可以被追平。

## 5. 增长引擎

**主引擎是 PLG，而且是最纯粹的那种：开发者自己刷卡，从 $10 免费额度开始。** 40 万开发者、5,000 家公司客户、无最低消费——注册到第一次调用不需要跟任何人说话。

三条辅助渠道，按重要性排：

1. **随客户一起长（最关键）**。Exa 真正的分发不是自己的市场费，是 Cursor、Cognition 这些客户的增长。它们每多跑一个 agent 任务，Exa 的账单就自动多一笔。这是把自己接到别人的增长曲线上——**也意味着它的天花板由客户决定，不由自己决定**。
2. **MCP + 生态占位**。Exa 很早就发了 MCP server，让任意支持 MCP 的 agent 一行配置接进来；上 Gemini Enterprise Agent Marketplace 是同一个动作的企业版。
3. **用评测做内容营销**。WebCode（编码 agent 检索评测）、学术检索 SOTA、「搜索质量如何影响 RL 效果」——它发的每篇技术博客都在说同一句话：拿数字比，我们赢。对一个买家全是工程师、且切换只要改几行代码的市场，这是唯一有效的话术。
4. **2026 年新增了传统销售**：C 轮同期挖了 LaunchDarkly 前总裁 Marcus Holm 当 CRO `[官方]`，并在 2026-03 落地新加坡。**从纯自助转向企业直销，是这家公司 2026 年最重要的组织变化**——也是收入结构将要变化的信号。

## 6. 风险与争议

1. **最大的风险是这篇报告本身写不出来的那个数：没有人知道 Exa 现在赚多少钱。** 三篇官方融资博客、a16z 的投资文章、所有媒体报道，**没有一处给出收入**。能查到的最新第三方估算停在 2026-01 的 $12M，而且两家第三方对 2025-09 的估算一个说 $10M、一个说 $12M，对 2024 年的估算一个说 $1.86M、一个说 $5.7M——**互相差 3 倍**。在这个空白上叠着一个 8 个月涨 3.1 倍、最后可查倍数约 183x 的估值。**看空的说法很简单：如果收入真的在飞，为什么不说？** 本档里 Mercor、Sierra、Glean 的里程碑都是公司自己喊出来的。

2. **零切换成本 × 纯用量计费 = 收入随时可以掉头。** 没有席位、没有年约、没有数据沉淀、没有资质门槛。客户换到 Parallel（$1/1k，Parag Agrawal 的公司，2026-04 也到了 $2B 估值、100,000+ 开发者）或 Brave（$4/1k）只需要改几行代码。更危险的是**客户不换供应商也能把账单砍掉**——agent 每次任务少搜五次，Exa 的收入就少一截，而客户正有强烈动机这么做（它们自己也在为 token 付费）。

3. **客户集中在编码 agent 这一个场景。** 官方点名的头部客户里，Cursor、Cognition、OpenRouter 都属于同一条产业链，且这条链本身正在经历残酷的价格战和整合。**具体集中度未公开**，但 Bryk 那句「几乎每个编码 agent 都在用我们」同时是卖点和风险披露。

4. **上游内置是结构性威胁，不是竞争。** OpenAI 和 Anthropic 的自带 web search 已是 $10/1k 的标准件，对客户零集成成本。Exa 现在赢在质量，但这是个可被追平的差距。Google 把 Exa 接进 Gemini 是今天的背书，也是明天的风险提示——**它证明了这件事值得做，而证明它值得做的那家公司，拥有全世界最大的索引**。

5. **赛道正在被并购收编。** 2026-02-10，Nebius 以 **$275M（对赌可至 $400M）收购了 Tavily** `[媒体，Bloomberg]`——Tavily 有 100 万+ 开发者、客户包括 IBM、Cohere、Groq。一个有百万开发者的同类公司卖了 $2.75 亿，而 Exa 的估值是它的 8 倍。这个对照要么说明 Exa 的自有索引确实值这个溢价，要么说明一级市场对 Exa 的定价脱离了这个品类的实际成交价。**Tavily 的成交价是这个赛道目前唯一一个被市场验证过的数字。**

6. **成本结构是重的。** 自购 GPU、爬虫带宽、索引存储——这些是固定成本，且必须持续投入才能维持「索引质量领先」这个唯一的护城河。收入 $12M、人头 110 的时候，这套成本是靠融资养着的。**它必须一直跑在增长曲线上，停下来就会被自己的固定成本压住**——这和 Higgsfield 那种「随时可以关掉 GPU」的转售模式是完全相反的风险形态。

## 7. 给我的启发

1. **「自己造」是真护城河，但护城河护的是质量差，不是客户。** Exa 是本系列 17 篇里左侧三格（自己造了什么 / 转手卖什么 / 抽掉 AI 还剩什么）答得最实的一家——它真的重造了一个索引，抽掉 AI 叙事后剩下的是一家小型搜索引擎公司。但它右侧两格（切换成本 / 上游内置）和 Higgsfield、Gamma 这些纯套壳公司**一模一样地薄**。这推翻了一个很流行的直觉：**自研深度和客户锁定是两回事**。自研让你今天搜得更准，它不让客户明天更难离开。要判断一家 AI 公司，这两件事必须分开问。

2. **当官方只肯披露用量、不肯披露收入时，先假设用量和收入之间有裂缝。** Exa 官方口径里有 500B URL、25 万亿 token/周、40 万开发者、5,000 家公司——唯独没有一个美元数字。对照本档：Mercor 喊 $2B、Sierra 喊 $200M、n8n 喊 €100M，公司自己喊收入是常态。**一家公司选择性披露哪个指标，本身就是最诚实的那个指标。** 反过来，它敢在 2026-03 涨价 40%，这个动作比任何 ARR 传闻都可信——**看它做的定价决定，比看它报的增长数字有用。**

3. **把自己接到别人的增长曲线上，是这一代基建公司最快也最脆的路。** Exa 的 11 倍增速本质上是 Cursor 和 Cognition 的增速的导数：客户的 agent 跑得越多，它的账单越大，全程不需要自己找一个新客户。Baseten（客户是最快的一批 AI 应用公司）走的是同一条路。这条路的好处是**增长几乎零边际获客成本**；坏处是**你的天花板和波动率都不由你决定**，而且你的客户正有动机优化掉对你的调用。判断这类公司，真正该盯的不是它自己的指标，是它前三大客户的指标——以及那些客户有多想少用你。
