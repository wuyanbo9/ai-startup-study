**它凭什么长这么快**：不是模型，不是 Agent，是**把一条采购否决项删掉，然后用包干价把 TCO 变成一个采购部门能一眼算完的数**。德国和欧洲大企业要全员上 AI，技术上第一天就能办——微软 365 Copilot 已经躺在它们的 EA 合同里。真正卡住的是另外两件事：第一，数据保护官和工会（Betriebsrat）要一份能过 GDPR 的答案，而「供应商是美国法人」在 Patriot Act 和 Cloud Act 面前就是一条过不去的否决项——Langdock 为此花了**双位数百万欧元**的税费和律师费，把 Delaware Inc. 改制成德国 SE `[媒体]`，这是一笔用现金买来的合规资产，不是一句话 positioning；第二，预算怎么批——Langdock 的做法是把 40 多家模型的推理成本**包进席位价里**，Work 席位 **€31.20/人/月（年付），551 席以上降到 €17.80** `[官方]`，比微软 365 Copilot 的 **$30/人/月** 还便宜，比 ChatGPT Enterprise 的 **约 $60/席位/月**（第三方口径，$45–75 区间）`[估算]` 便宜一半以上，而且没有「用超了再追加预算」这件事。于是 CIO 不需要赌用量，只需要数人头。灯塔客户把这套话术坐实了：**Merck 把它铺给了 63,000 名员工 `[媒体]`，目前报告 33,000+ 月活 `[官方]`**——这个数字之后，BASF、Würth、Trumpf、Der Spiegel、Süddeutsche Zeitung、The Economist、Statista 一路跟上 `[官方]`。**但本篇最该记的不是增速，是分母**：客单价在同一段时间里从约 €5,300/年掉到约 €4,000/年（见第 6 节），它正在用越来越多的小客户换 ARR。

## 1. 核心产品

**卖什么**：一个「全公司 AI 接入与管控层」。九个模块装在一个工作区里：Chat、Workflows、Agents、Meetings、Apps、Code、Governance、Integrations、API `[官方]`。对员工来说它长得像一个企业版 ChatGPT，但背后可以路由到 **40+ 个模型**（GPT、Claude、Gemini、Mistral 等）`[官方]`；对 IT 来说它是 SSO/SCIM/SAML + 权限 + 审计 + 「数据绝不用于训练」的承诺 `[官方]`；对部门来说它是一个不用写代码就能搭 agent 和 workflow 的地方。

**部署形态是产品的一部分**，这一点比功能表更重要：Azure 欧盟区 SaaS、Langdock 托管的专属部署、客户自己的云、以及 Kubernetes 上的 on-premise `[官方]`。认证齐了 ISO 27001 与 SOC 2 Type II `[官方]`。2026 年公司还在德国自建第一个机房，投资 €1,000–1,500 万、可扩到 50 兆瓦 `[媒体]`。

**什么场景打开**：员工侧是「每天想用 AI 干点活但公司不让用 ChatGPT」的那一刻——频次是每天数次，疼在影子 IT：人要么偷偷把合同贴进个人账号（法务风险），要么干脆不用（生产力损失）。IT 侧是「CEO 让我们三个月内全员上 AI」的那一刻——频次是一次，疼在它同时要过数据保护官、工会、采购和安全四道审查。

**Before / After**：

| | Before | After |
|---|---|---|
| 一个员工想用 AI 改一份合同 | 要么贴进个人 ChatGPT（违规），要么不做 | 在公司工作区里做，有审计记录 |
| 换模型 | 跟一家模型厂签一份企业合同，锁死 | 工作区里切，40+ 模型共用一个合同 |
| 数据保护官审查 | 审一家美国公司的跨境传输，几个月 | 德国 SE + 欧盟托管/自托管，审查项少一半 |
| 成本预测 | 用量制，月底才知道花了多少 | €17.80–31.20/席位/月，模型费已含 |
| 部门自己做自动化 | 排进 IT 的 backlog | Workflow 里自己搭，IT 管权限 |

**替代了什么**：它替代的**不是人力，是另一份软件合同**——微软 365 Copilot、ChatGPT Enterprise、或者一个内部团队自建的 LLM gateway。这个区分很要命：抢软件预算的天花板是「每人每年几百欧元」，抢人力预算的天花板是「一份年薪」，差一个数量级。本档里 Harvey 和 Hippocratic AI 抢的是人力预算，Langdock 明确抢的是软件预算——所以它的增长只能靠**铺席位数**，不能靠**抬单价**，而这正是它客单价下滑的结构性原因。

## 2. 商业模式

- **收费对象**：**IT / CIO 的集中软件预算**，按全公司席位数买。用的人和批钱的人不是同一批，但这里的错位很浅——员工受益、IT 签字，而 IT 的 KPI 就是「员工真的在用」，所以两边是同向的。这也解释了为什么公司对外反复引用「Merck 33,000 月活」而不是「Merck 买了多少席位」。
- **定价结构**（全部来自官方定价页，欧元、不含增值税、年付省 20%）`[官方]`：
  - **Core 标准席位 €23.20/人/月（年付）/ €29.00（月付）**；Max 席位（5 倍用量）**€99.00**。含 40+ 模型的 Chat、自定义 agent、skills、集成、SSO/SCIM/SAML、每月 2,500 次 workflow run、每人每月 10 场会议转写。
  - **Work 标准席位 €31.20/人/月（年付）/ €39.00（月付）**；Max 席位 **€109.00**。加上 Governance（合规与访问控制）、不限场次会议（公允使用上限每人每周 60 小时）、全工作区分享、每月 10,000 次 workflow run。
  - **量价阶梯（年付标准席位）**：Core €23.20（1–50 席）→ €19.20（51–250）→ €15.20（251–550）→ **€12.80（551+）**；Work €31.20 → €25.80 → €20.72 → **€17.80（551+）**。
  - **Enterprise**：定制报价，面向 1,000+ 人的铺开，含专属部署与定制 workflow 额度。
  - **Workflows 加购**：€449/工作区/月（年付）换 40,000 次 run；FAQ 另提 €999/月 换 100,000 次。单个 workflow 默认上限 2,000 步，未用完的 run 按周期清零。
  - **API 加购**：按 token 计价、在模型原价上加成，例如 GPT-5.5 €4.93/€29.57 每百万 input/output，Opus 4.8 €4.93/€24.64，Gemini 3.1 Pro €1.79/€10.75 `[官方]`。
  - **试用**：7 天免费、不要信用卡、送 €5 模型额度 `[官方]`。
- **单位经济 —— 这是本篇最值得抄的一段**：
  - **「模型费已含」是它最锋利的武器，也是它最大的敞口。** 席位价里包干推理，意味着成本波动全部由 Langdock 自己吃。那么成本有多少？官方没披露，但定价表自己泄露了答案：**Max 席位（5 倍用量）比标准席位贵 €77.80，折算每一份「用量包」的零售价约 €19.45**；而这个零售价是在模型原价上加成后的数（API 加购页摆明了加成），按加成后成本率 50–60% 反推，**一个标准 Work 席位的满额推理成本约 €10–12/月，占 €31.20 席位价的 32–38%** `[估算]`。对应**毛利率约 62–68%**，低于传统 SaaS 的 80%+，但远好过纯用量转售。
  - **真正让它盈利的，是「买了不用的那一半席位」。** Merck 买了 63,000 人的覆盖，月活 33,000——**激活率约 52%**。企业全员铺开后必然有一条长尾：从不打开的人贡献满额席位收入、零推理成本。**席位制 + 包干用量，在高渗透低激活的场景里是一台印钞机**；反过来，一旦激活率往上走（这恰恰是 IT 的 KPI），毛利就被压。这个矛盾没有解法，只有补丁——Max 席位就是那个补丁。
  - **成本结构里几乎没有销售。** 65 人做 €6,000 万 ARR 且盈利，意味着它不是靠 AE 扫楼签下 15,000 家公司的。7 天免费试用 + €23 起的自助席位承接长尾，大客户靠 Merck 这类灯塔的从众效应。**这是「低融资高 ARR」的真实机制，不是什么运气。**
  - **€270 万外部资金撑起 €1,000–1,500 万的自建机房**，只能来自经营现金流（公司称有双位数百万欧元现金盈余）`[媒体]`。这是一个完全不同于美国同行的资产负债表叙事。

**不可替代性（必答，且必须写短）**

| 问题 | 答 |
|---|---|
| **自己造了什么** | 把 40+ 模型推理包进 €17.80–31.20/席位固定价仍盈利的成本路由与用量分层 |
| **转手卖什么** | OpenAI/Anthropic/Google/Mistral 的推理 + Azure 欧盟算力，约占席位价 32–38% `[估算]` |
| **抽掉 AI 还剩什么** | 一层过了 ISO 27001/SOC 2 的欧盟托管与权限审计中间件，加一座在建机房与一个德国 SE 法人 |
| **换掉它要付什么** | 重走德企 IT／数据保护官／工会审批，3–6 个月；已建 workflow 与 app 要重做。但对话和 prompt 可导出，无数据锁定 |
| **上游原生做了会怎样** | 模型厂补齐欧盟数据驻留与多模型路由后，它只剩「德国法人地」和「低价」两条 |

**不可替代性：中。** 护城河不在技术栈里，在两样花钱买来的东西上——双位数百万欧元换来的德国 SE 法人地（删掉一条采购否决项）和 €1,000–1,500 万的自建机房（删掉对美国云的依赖），加上一套真实有效的推理成本工程。这三样对手都能复制，但复制要掏同样的现金和同样的时间；而技术层面，抽掉上游模型后它剩下的是一个权限审计中间件——这就是它只能是「中」而不是「强」的原因。

## 3. 北极星指标

- **North Star（推断）**：**每家客户的「已付席位周活渗透率」（WAU ÷ 已采购席位）**。
- **为什么是它**：这家公司对外只反复引用一个运营数字——「Merck 33,000+ 月活」，而不是「Merck 买了多少席位」或「合同金额多少」。原因在商业模式里：它按全公司席位收年费，续约那天 IT 必须向 CFO 证明这笔钱买到的不是一堆没人打开的账号。渗透率跌，续约就跌，而**渗透率是 ARR 的领先指标，领先一个合同周期（12 个月）**。反过来它也是毛利的先行指标——渗透率涨，推理成本涨，所以这个数既是收入的油门也是毛利的刹车，公司内部必然天天看。
- **配套指标（2–3 个）**：
  1. **净收入留存（NRR）**——席位制公司的扩张全靠「同一个客户买更多席位」，15,000 家客户的分母已经很大，下一阶段的增长必须来自 NRR 而不是新签。
  2. **每席位月均 workflow runs**——Core 包 2,500 次、Work 包 10,000 次，这个数既衡量「有没有从 Chat 用到自动化」（用深了才换不掉），也直接决定成本。
  3. **客单价（ARR ÷ 客户数）**——目前在掉（€5,300 → €4,000），这是公司最不愿意公布、也最该被外部盯住的一个数。
- **它不盯什么**：客户数。从 3,000 涨到 15,000 很好看，但如果单价同时掉 25%，这个数就是在讲一个比实际更乐观的故事。

## 4. AI 在业务中的作用

| 层次 | 它的情况 |
|---|---|
| **AI = 产品本身** | **是，但是转售式的。** 没有上游模型，这个产品不存在——它的本体就是模型分发与编排。但它自己不训练任何模型，所有智能来自 40+ 家外部 API。所以准确的说法是：AI 是它的**商品**，不是它的**技术**。 |
| **AI = 效率杠杆** | **极强，而且是本篇最该抄的一条。** 65 人做 €6,000 万 ARR 且盈利（约 $106 万/人，传统 SaaS 上沿的 4–7 倍）。杠杆点不在工程而在 GTM：7 天免费试用 + €23 起的自助席位把长尾客户的获客成本压到接近零，15,000 家客户不是靠 AE 签下来的。 |
| **AI = 营销标签** | **有一部分，要点破。** 官网摆着 Agents、Workflows、Code 九个模块，但在相当比例的客户那里，实际用法仍然是「一个合规的 ChatGPT 替代品」——Merck 的部署对内就叫 myGPT Suite，本质是一个聊天入口。Workflow 额度（Core 2,500 次/月）折到人头上每人每天不到几次，也侧面说明自动化还不是主用途。**把 Agent 叙事折价看，剩下的生意依然成立，但它是一个「合规接入层」的生意，不是一个「自动化平台」的生意。** |

**自研还是调 API**：**全部调 API，40+ 家**，不训练模型。模型层依赖度是本档里最高的几家之一。

但依赖的**形状**值得分开看：它是**多源依赖**而非单源依赖。任何一家模型厂涨价、降质、出合规事故，它都能把流量切走——这既是它敢做包干定价的前提（没有议价劣势），也是它对客户的核心卖点（不被单一供应商锁死，这正是 2024 年 TechCrunch 报道那轮融资时的原话：帮企业避免 LLM 的 vendor lock-in）。代价是：**它在任何一家模型厂眼里都只是一个批量采购渠道，没有任何独占内容或独占数据**。

**模型升级是利好还是威胁**：
- **短期明确利好。** 产品免费变强，它一分研发钱不用花；而且每次有新模型出来，「我们接了 40+ 个你随时切」这句话都更值钱一点。
- **长期明确威胁，而且威胁点很具体。** 它今天卖的三件东西——欧盟数据驻留、多模型中立、固定席位价——其中第一件模型厂已经在做（企业版的欧盟数据驻留选项），第三件是定价策略不是技术壁垒。**真正只有它有的是第二件和「德国法人」**。模型厂越强，「多模型中立」的价值就越低（如果一家明显领先，中立就不值钱了）；而德国法人地这件事，任何愿意花同样钱的对手都能买。

## 5. 增长引擎

主引擎是**灯塔客户驱动的从众采购**，不是 PLG，也不是 SLG。

1. **Merck（主引擎）**。2024 年就铺到 63,000 名员工 `[媒体]`，首席数据与 AI 官公开称它是「全公司的 AI 伙伴」`[官方]`。在德国 B2B 市场，一家 DAX 制药巨头的数据保护官点了头，等于替后面所有人做完了尽职调查。之后 BASF、Würth、Trumpf、Eppendorf、Axpo、SumUp、Der Spiegel、Süddeutsche Zeitung、Frankfurter Allgemeine、The Economist、Statista、mobile.de、UNICEF、多特蒙德足球俱乐部一路跟上 `[官方]`。
2. **「主权 AI」这条政治顺风**。2026-11-03 柏林数字峰会上，KI Bundesverband 与 Startup-Verband 把「年度主权 AI」奖颁给它 `[媒体]`。欧洲企业和公共部门对美国云的焦虑是真金白银的采购偏好，而它是少数把这件事做到法人层面的供应商。
3. **自助层承接长尾**。7 天免费试用、不要信用卡、Core €23.20/席位起、量价阶梯自动降价 `[官方]`——这条路让一家 200 人的公司不需要跟任何销售说话就能上线，这是客户数从 3,000 冲到 15,000 的机制，也是客单价下滑的机制。
4. **雇主品牌反哺**。LinkedIn Top Startups 2026 德国榜第一（评估期 2025-07 至 2026-06，权重是员工增长、平台互动、岗位关注度、吸引顶尖人才的能力）`[媒体]`——注意这个榜衡量的是**招聘热度，不是业务指标**，别当增长证据用，但它确实在德国市场买到了免费曝光。
5. **几乎没有融资新闻这条渠道**。两年半只有一笔 2024-04 的 $3M 种子轮被报道过，它的媒体曝光全部来自业务里程碑和客户。这跟本档里大多数公司（靠一轮接一轮融资新闻刷存在感）正好相反。

## 6. 风险与争议

1. **客单价在掉，这是最硬的看空证据。** 2026-01 约 3,000 家客户 / €1,600 万 ≈ **€5,300/户/年**；2026-11 15,000+ 家 / €6,000 万 ≈ **€4,000/户/年** `[估算]`。客户数涨 5 倍，ARR 只涨 3.75 倍。差额来自自助渠道涌进来的小单。这类客户的续约率、扩张率都远不如 DAX 大客户，**所以今天的 €6,000 万 ARR 里，稳态续费的成分比看起来要少**。而公司从未披露 NRR 或客单价。
2. **ARR 口径本身要打折。** €6,000 万是公司自报的「按当前订阅额年化」，德语媒体明确标注过这不是审计数、也不是已收到的收入。€5,000 万 → €6,000 万这一跳只隔两个月，而上一次公开点（€5,000 万）在不同来源那里被标成 8 月、9 月、10 月三个不同月份——**这种时间点的混乱，通常意味着里程碑是按发帖节奏公布的，不是按财务周期**。
3. **包干定价与激活率的内在矛盾（结构性）。** 盈利很大程度上来自 Merck 那种 52% 激活率下「不用的那一半席位」。IT 买它就是为了提高激活率；激活率每涨一点，推理成本就吃掉一点毛利。Max 席位（€109，5 倍用量）是补丁。**如果 agent 和 workflow 真的普及起来——也就是公司的产品路线成功——单位经济会变差，而不是变好。**
4. **微软是结构性对手，而且不讲道理。** 365 Copilot 已经在这些企业的 EA 合同里，Copilot Chat 更是 **$0**。微软可以把价格打到任何位置，因为它的收入来自别处。Langdock 的价格优势（€17.80 vs $30）不是成本优势，而是「不卖捆绑」的选择；这个优势一旦微软决定免费送，就归零。
5. **上游整体上移的风险，落点很具体。** OpenAI、Anthropic、Google 都在往企业治理和部署形态上走。它们补齐欧盟数据驻留那天，Langdock 三张牌里最厚的一张就薄了，剩下的「多模型中立」价值取决于模型之间继续互有胜负——**这是一个它完全无法控制的外部变量**。
6. **零融资的双刃。** €270 万撑起 €6,000 万 ARR 是一个漂亮的故事，但 €1,000–1,500 万的自建机房、双位数百万欧元的法人改制费，全部从经营现金流里出。**账上没有融资缓冲**：一旦增长放缓、或者微软真的打价格战，它没有可以烧的钱。而反过来，长期不融资也可能意味着它在刻意回避一次会把真实留存率摊开给尽调看的定价。
7. **估值真空本身就是个争议。** 投资人说「轻松值几十亿欧元」，二级数据商给 $12–18M，官方没有现行估值。**这中间差三个数量级**，任何引用都应该标明口径。

## 7. 给我的启发

1. **「包干定价」是 AI 应用层最被低估的武器，但它的前提是你算得准成本。** 把推理费包进固定席位价，换来的是采购部门能一眼算完的 TCO——这在企业采购里几乎是降维打击，因为它消除的不是价格，是**不确定性**。但敢这么定价有两个前提：你有 40+ 个模型可以路由（所以没有议价劣势），以及你的客群是「高渗透低激活」的全员铺开（所以长尾用户替你付钱）。**反过来看，一家坚持用量计费的 AI 公司，往往是因为它不敢赌自己的成本曲线。** 下次看一家 AI 应用公司，先看它的定价页敢不敢包干。
2. **合规和法人实体可以是真护城河，但它是用现金买的，所以也能被现金买走。** Langdock 愿意花双位数百万欧元把 Delaware Inc. 改成德国 SE，不是情怀，是因为「供应商是美国法人」在德国企业的数据保护审查里是一条**否决项**，而不是一个减分项。把一条否决项删掉，价值远大于把十个功能做好。判断一家欧洲 AI 公司，第一个问题应该是：**它有没有把客户采购流程里那条否决项拿掉？** 但同样要记住，这类护城河的宽度等于复制它的现金成本和时间成本——它拦得住懒的对手，拦不住有钱的对手。
3. **融资额小是正向信号的概率，比大更高。** ARR ÷ 累计融资，Langdock 是约 22x，本档大多数同体量公司是 0.1–0.5x。这个比值直接量化了一件事：**产品是自己走出去的，还是花钱推出去的。** 它也解释了为什么 65 个人能做到 €6,000 万——不需要养一支销售军队的公司，人效自然就是别人的 4–7 倍。但要配一个反向检查：**融资少也可能意味着它在回避一次会把真实留存摊开的尽调。** 所以这条指标要和客单价趋势一起看——Langdock 的客单价正在掉，这就是那个该让人警惕的地方。
