## 赛道覆盖

分类法见 SKILL.md 第 2 步的受控词表：`layer` 答「在栈的哪一层」，`sector` 答「谁掏钱买」。下面按 layer 分组，括号内为家数。

**Infra（3）**

- Infra 与推理：Baseten、fal、Modal（三篇可对照：跨云转售 GPU 的推理平台 / 生成媒体专用推理 / 按秒计费的容器与 agent 沙箱。三家都不自有机房，都靠机队利用率赚毛利，可放在一起看这类生意的共同弱点）

**模型与数据（5）**

- 数据与评测：Mercor、Arena、AfterQuery、Snorkel AI（四篇可对照：给实验室雇专家的双边市场 / 收被评级方钱的排行榜 / 按项目卖专家推理数据与 RL 环境 / 软件公司砍掉软件团队转型数据工厂。Snorkel 与 AfterQuery 卖的东西几乎相同，但一家按工时、一家按成品计价，估值倍数 16x 对 9.3x；Snorkel 与 Arena 共享同一个结构性问题——靠评测建立权威、收入来自被评测方）
- 设计与创作：Suno（本档唯一一家自己从零训练生成模型、并直接向消费者收订阅费的公司；与应用层的 Gamma、Meshy 对照看「自研模型」与「包装上游」在估值倍数上的差别）

**Agent 与开发者基建（3）**

- Agent 基建与自动化：Retell AI、n8n、Exa

**应用（30）**

- 法律：Harvey、Legora（同赛道两篇，可横向对照）
- 工业与制造：ChipAgents（半导体 EDA）、Carbon Robotics（农业机器人）、Flow Engineering（硬件系统工程的需求记录系统）（三篇可对照：三家都卖给「造实物的人」，但抢的预算层级完全不同——ChipAgents 抢验证工程师的编制、Carbon Robotics 抢除草工时并且收入是一次性设备款、Flow 抢的是一张在位软件只值 $400/席/年的表，靠换参照物把它卖到 $1,800–3,600/席/年）
- 销售与市场：Clay、Higgsfield、Profound（三篇可对照：数据丰富化 / 素材生产 / 可见度测量）
- 设计与创作：Gamma、Meshy
- 客服与支持：Sierra、Decagon、Wonderful（三篇可对照：按结果付费的托管部署 / 按对话计费 + 客户自己改流程 / 非英语市场 + 驻场工程师把 agent 接进无 API 旧系统。第三家最值得和前两家并读——同一个品类里，它是唯一把「上线」而不是「模型」当产品卖的，代价是毛利只有 52%、人均创收 $10.8 万，形状更像系统集成商而不是 SaaS）
- 开发与编程：Lovable、CodeRabbit（两篇可对照：让 AI 生成整个 App vs 给 AI 生成的代码做审查闸门——同一波繁荣的上游与下游）
- 人力与招聘：Juicebox
- 财务与会计：Rillet、Numeral（两篇可对照：把 NetSuite 换掉的 AI 总账 vs 把销售税申报做成按次商品的合规代理；同属财务预算，但一个抢软件预算、一个抢事务所人工）
- 安全：Cyera、HiddenLayer（两篇可对照：企业上 AI 前先答「模型能看到哪些数据」 vs 上线前后给模型和 agent 本身做清点、扫描与拦截；同属 AI 治理预算，但后者的品类正被平台厂商整体收购吞并）
- 医疗健康：OpenEvidence、Heidi、Hippocratic AI（三篇可对照：医生免费/药企买单的广告模式 / 医生自己刷卡的低价席位制 / 按 agent 小时向医院护理预算收费的患者外呼。第三家是本档唯一一家「替代的那件事原来根本没发生」的公司——没有存量预算可搬，也没有被裁掉的人站在对面）
- 金融与保险：Corgi、Rogo（两篇可对照：自己拿牌照承保 vs 卖给投行的席位制 agent）
- 物流与供应链：HappyRobot
- 地产与建筑：EliseAI
- 政府与公共部门：Peregrine
- 教育：Speak
- 零售与电商：RADAR（实体门店的实时库存定位，本档唯一一家硬件占大头的公司）

**分布本身就是一个结论**：41 家里 30 家在应用层，基建与模型层合计 11 家。

**待覆盖**：应用层里的医疗行政收入侧（RCM / 预授权，如 Adonis、Tennr 一类）、供应链计划（物流与供应链现只有 HappyRobot 一家货代话务）；零售与电商里的纯线上一侧（agentic commerce、AI 导购、agent 支付轨道如 Natural / Wildcard / Skyfire 一类——本次扫榜发现这一片目前还没有一家拿得出绝对收入数字，最大的公开 ARR 仅七位数，故本期未选）。
