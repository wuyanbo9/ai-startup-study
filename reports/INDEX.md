**本轮（2026-11-10）扫榜的落选记录**，供下次省掉重复功课：赛道约束是「不能撞金融与保险 / 零售与电商 / 物流与供应链」（最近三篇 Qualitate / Santé / ClearJet）。本轮先扫近期高增长榜单与融资新闻，逐家查过的落选项：①**法律**本轮最想选的是 **Supio**（原告侧人伤与大规模侵权案的律所 AI，官方口径「自走出隐身以来 ARR 增长 17x」，2026-H1 客户数翻倍、推出 Supio Agent），但最新融资仍停在 2025-04 的 $60M B 轮（Sapphire 领投，累计 $91M），**公司只给倍数不给任何基数，且 2026 年无新一轮重新定价**，同时 `法律` 一格已有 Harvey / Legora / GC AI 三家，留待它披露绝对收入或新一轮后再做；同格的 EvenUp（累计 $3.85 亿）属同一细分，一并押后。②**安全**里的 **Sentra**（2026-11-04 宣布 $150M C 轮，官方称过去一年增长 >300%）增速够、时间够新，但它与本档已有的 **Cyera** 是同一细分（数据安全态势管理）的直接竞品，正文会与 2026-09-10 那篇大段重复，判定为学习价值低。③**销售与市场**里的 **Nooks**（2026-11 从 General Catalyst 的 Customer Value Fund 拿 $5 亿增长资金）数额最抢眼，但公开增速只有约 3x YoY，且这一格已有五家。④**医疗健康**里的 **Doctronic**（某榜单给 800% 增长、$40M B 轮、30 万+ 周活）与 **Parakeet Health**（2026-10-01 $10M A 轮、标题写 10x）都只有二手榜单口径、无一手披露，且 `医疗健康` 已有四家。⑤**教育**本轮是最空的一格（76 家里仅 2 家），候选三家逐一排除：**Pingo AI**（2025-01 上线、官方口径约 8M 用户 / 约 $12M ARR、仅融 $50 万种子，增速最猛）落选的理由是**它与已覆盖的 Speak 在产品形态与买家上几乎完全重合（都向学习者本人收订阅做口语练习），且所有数字均为自报或第三方估算、没有定价页也没有一手新闻稿**，不满足「至少三个独立来源 + 官方定价页」这条硬杠；**Subject**（$14M ARR、2026-02 融 $2,800 万）与 **SchoolAI**（$25M A 轮、400+ 学区）体量与披露都不如 MagicSchool；**Brisk Teaching**（2026-07 称 200 万+ 教师、Bessemer 领投 $15M A 轮）零收入披露。⑥**本轮选中 MagicSchool 的理由，以及一条可复用的新做法**：它满足第一梯队的硬标准（2024-01 开始收费 → 约 12 个月破 $10M ARR），赛道是最空的一格，且恰好是本档目前**唯一一个「上游原生做了、而且做了整整一年」的受控实验** —— OpenAI 的 ChatGPT for Teachers 自 2025-11-19 起对全美 K-12 教师免费、自带学区级管控与 FERPA 合规，逐项覆盖它的免费层，而它的注册教师在这一年里从 400 万涨到 800 万。**可复用的新做法：当一家公司只公布注册量、从不公布付费转化时，用「官方自己愿意送出去的那个额度」反推客单价上限。** 本篇的学区合约锚点不是来自任何分析师估算，而是来自它与 Horace Mann 联名抽奖的新闻稿 —— 头奖写的是「最高 $25,000 的一年期学区订阅额度」，一个公司当头奖送出去的额度通常就落在它典型大合约的量级上；再配上创始人访谈里的试点价（单校 $1,000 / 整区 $2,000，不论规模），就能在没有任何 ARR 披露的情况下把收入区间夹到 $2,800–5,000 万，并且顺手看清它真正的护城河是审批层级套利而不是模型。遇到「只报用户数不报收入」的公司，**新闻稿里的赠品额度、抽奖头奖、合作社挂牌价这三类数字，比任何第三方 ARR 估算都可靠**。

**本轮（2026-11-12）扫榜的落选记录**，供下次省掉重复功课：赛道约束是「不能撞法律 / 教育 / 金融与保险」（最近三篇 Manifest OS / MagicSchool / Qualitate）。①**Gallatin AI**（军事后勤、2026-10-08 的 $50M A 轮、8VC 与 Silent Ventures 参与、累计 $70M、Navigator 已被陆军与空军采用）—— 政府与公共部门只有两家、位置很空，但**全网找不到任何收入数字或带日期的用量指标**，连区间都夹不出来，不满足「增长速度是证据」这条硬标准，无法成篇。②**Augment**（货代 AI 助理 Augie、累计 $110M、称管理 $35B+ 货运、Penske 2026-01 签约、110+ 工程师）—— 第三方拆解明确写了「到 2026-07 从未公布 ARR、席位数或单票价格」，而且公司自己说不抽运费差价，所以 $35B 这个数**不可转换为收入**，是典型的「体量数字掩盖收入空白」。③**Lyzr AI**（企业 agent 控制平面，创始人 2026-11 发帖称 12 个月从 $650K 做到 $15M、95% 毛利、五个 $1M+ ACV 客户）—— 增速 23x 比 Langdock 更猛，但**唯一来源是创始人一条 X 发帖**，没有第二个独立来源，交叉验证不过关；留到有媒体或官方口径之后再看。④**Magentic / Lio / Atomic**（采购与供应链计划侧）—— 仍是上一轮的结论，A 轮规模、无绝对收入数字。⑤**本轮选中 Langdock 的理由，以及一条可复用的新做法**：它是本档第一个**分母比分子更值得记的样本** —— €6,000 万 ARR 不算惊人，但「累计外部融资只有 €270 万、2024-04 后再未融资、65 人、已盈利、还从经营现金流里掏 €1,000–1,500 万自建机房」这一组数字放在一起，构成了一个与本档其余 77 家完全不同的资产负债表叙事（ARR/累计融资约 22x vs 其余 0.1–0.5x）。**可复用的新做法一：当一家公司不披露毛利或推理成本时，去它的定价页找「高用量席位」与「标准席位」的差价，那个差价就是它自己给用量包标的零售价。** Langdock 的 Max 席位（5 倍用量）比标准席位贵 €77.80，折算每份用量包零售价约 €19.45，再按它在 API 加购页上公开的加成幅度反推成本率 50–60%，就能把「推理成本占席位价 32–38%、毛利 62–68%」夹出来 —— 全部材料都在官方定价页上，不需要任何内部信息。**可复用的新做法二：把「法人注册地」当成一个可定价的产品特性去查。** Langdock 花双位数百万欧元把 Delaware Inc. 改制成德国 SE，理由是「供应商是美国法人」在德企的数据保护审查里是一条**否决项**而非减分项 —— 删掉一条否决项的价值远大于做好十个功能。看任何一家卖给欧洲大企业或公共部门的 AI 公司，先问「它有没有把客户采购流程里那条否决项拿掉」，这个问题比看它的模型选型更有分辨力。**反面一并记住：它的客单价正在掉**（2026-01 约 €5,300/户/年 → 2026-11 约 €4,000/户/年，客户数涨 5 倍而 ARR 只涨 3.75 倍），而且它的盈利很大程度上来自「买了不用的那一半席位」（Merck 激活率约 52%）—— 产品路线成功反而会压毛利，这是包干定价模式自带的矛盾。
