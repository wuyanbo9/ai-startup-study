**它凭什么长这么快。** 三件事，按贡献排序，一件都不是「模型变强了」。

**第一件是降价。** 2024-12-10 Devin 正式开卖时是 **$500/月起、不限席位** `[官方]`，那是一个「先签合同再试用」的价格，九个月后年化只有约 $1M `[第三方]`。2025-04-03 的 Devin 2.0 把入门价砍到 **$20** `[官方]`，同时放开并行会话。此后九个月，年化从约 $1M 做到 **$73M** `[第三方]`。在 agent 这类「用量即学习」的产品里，定价结构的一次改动比模型升级更能改变曲线——这是全篇最该记住的一条。

**第二件是买分发。** 2025-07-14 它收购 Windsurf，官方博客（Scott Wu 发给全员的信原文）写明买到的是：Windsurf IDE、商标与 IP、**$82M ARR 且企业 ARR 季度翻倍**、**350+ 企业客户**、几十万日活 `[官方]`。价格始终未披露 `[CNBC：未披露条款]`。前情是 Google 刚付了**约 $24 亿**只做技术授权并挖走 CEO Varun Mohan 等核心人，不持股 `[媒体，CNBC]` —— 也就是说，被巨头 acquihire 掏空后剩下的「残骸」（一个被用户喜欢的 IDE、一支 GTM 团队、350 份企业合同），Cognition 以一个没公布但显然远低于 $24 亿的价格整锅端走。14 个月后，这家公司年化 $1B。

**第三件是把采购阻力拆掉。** 2026-06-04 官方推出 **AI Productivity Guarantee**：如果 Devin 交付的工程价值低于客户付的钱，Cognition 自己掏钱补用量，**上限 $10M**，直到补平 `[官方]`。配套是一个自研的估算器——让一个 agent 逐会话判断「这次有没有产出有用结果」「换人类工程师要花几小时」，对照企业用户的人工估时校准，官方公布 r_log = 0.74 `[官方]`。再加上 FedRAMP High In-Process（2026-07-13）`[官方]`、与 AWS 的多年战略合作（2026-09-15）`[官方]`、与美国能源部 Genesis Mission 的 MOU（2026-07-22）`[官方]`，它把「这东西到底有没有用」这个采购里最难回答的问题，变成了合同里的一行数字。

## 1. 核心产品

**卖什么。** 一句话：**按量批发「一个初级工程师 4–8 小时能干完的活」**。

官方自己 2025-11-14 的《Devin 2025 年度绩效评估》把适用边界写得比任何第三方评测都狠：Devin 擅长的是「需求清楚、结果可验证、人类初级工程师要 4–8 小时」的任务，典型是仓库迁移与现代化、修静态扫描（SonarQube / Veracode）扫出来的漏洞、补单元测试、清小工单；它「在理解代码库上是资深水平，在执行上是初级水平，产能无限但不会沟通」`[官方原话]`。

**三个形态**（2026-10-11 抓取官网）：
- **Devin Cloud / Web** —— 云端并行 agent，入口是 Slack、Jira、Linear、GitHub；活干完直接提 PR，人类只做 review。
- **Devin Desktop** —— 就是 Windsurf IDE，2026-06 改名 `[第三方]`，是自助用户的主入口。
- **Devin CLI + API + DeepWiki** —— DeepWiki 是它给代码库自动建的索引，既是产品也是 agent 的上下文来源。

2026 年新增的三个方向都在往「写完代码之后」走：**Auto-Triage**（线上事故第一轮排查）、**Security Swarm**（找并分级漏洞）、**Automations**（Slack/GitHub/Linear 里的事件直接触发任务，不用每次开对话）`[官方，E 轮博客]`。TierZero 和 Poke 两支团队也是 2026-07 买进来补这一段的 `[官方]`。

**Before / After。**

| | 原来 | 现在 |
|---|---|---|
| 清积压工单 | 排进 sprint，或者招人 / 外包；一个初级工程师一天两三件 | 一次开几十个会话并行跑，夜里也跑；官方口径 **67% 的 PR 被合并**（2025-11，上一年同期 34%）`[官方]` |
| 修静态扫描漏洞 | 安全组提单、工程组排期，拖几个季度 | 官方举的客户例子：一家大型机构把总开发时间的 **5–10%** 省了下来，另一家拿到 **20x 效率** `[官方，客户口径]` |
| 遗留系统迁移 | 立项、估月 | Mercedes-Benz 的 COBOL 现代化被评论引述为「估 8 个月压到 8 天」`[公司口径经二手媒体转述，未见官方原文]` |

替代的是**人**，不是软件 —— 这一点决定了它的天花板（见第 2 节）。

## 2. 商业模式

- **收费对象**：企业工程组织的人力/工程预算（企业合同为主），加一条自助的个人开发者长尾。
- **定价结构**（2026-10-11 抓取 devin.ai/pricing）`[官方]`：

| 计划 | 价格 | 关键内容 |
|---|---|---|
| Free | $0 | 轻量额度、模型受限、无限 inline edit 与 Tab |
| **Pro** | **$20/月** | 完整模型可用（OpenAI / Claude / Gemini / xAI 及开源模型）、Devin Cloud、SWE-2 在 Devin Desktop 与 CLI 内**免费用到 2026-10-16**、超额按 **API 价**另买 |
| Max | $200/月 | 额度大幅提高 |
| **Teams** | **$80/月 + $40/席/月**（≤200 人） | 共享协作、集中计费、管理后台、优先支持 |
| Enterprise | 面议 | VPC 部署、SAML/OIDC、专属支持、自定义条款 |

**定价的三次变身本身就是这家公司的历史**：$500/月不限席位（2024-12）→ $20 起 + 按 ACU 用量（2025-04 起，一个 ACU 约 15 分钟）→ 席位 + 额度 + 超额按 API 价（2026 现行）。三年换三套，最后收敛到和 Cursor 同一个形状：**低价席位做入口，真正的钱在额度超额和企业合同里**。

- **它从谁的预算里抢钱**：**人力预算**。参照价是一个初级工程师的年薪——美国本土量级 $120–150K/年，离岸外包 $30–60K/年 `[估算，公开薪酬区间]`。而 Teams 的席位年费是 **$480/席** 。这个价差（两个数量级）既是它卖得动的全部理由，也是天花板高的理由。
- **一道除法，看清这 10 亿是谁付的**：自助 Pro 年费 $240、Teams 席位年费 $480。$1B ÷ $240 = **417 万个付费 Pro**，$1B ÷ $480 = **208 万个付费席位** —— 对一个成立不到三年的开发工具来说都不成立。所以这 10 亿**必然压倒性地来自企业合同与用量超额**，而官网写明超额「按 API 价」计费。**也就是说，收入结构里有一块规模未公开、但一定不小的部分，本质是把上游前沿模型的 token 加价转卖。**
- **单位经济**：毛利率从未公开 `[未公开]`。但有两个硬证据指向「不好」：一是 The Information 口径的租卡年花数亿、今年烧钱可能 $800M `[媒体]`；二是它自研 SWE-2 的全部卖点就是**同分省 64% 推理费** `[官方]` —— 一家公司花最强的研究力气去压自己的推理成本，说明毛利是靠这个往回抠的。

**不可替代性（必答）**

| 问题 | 答 |
|---|---|
| **自己造了什么** | Fusion harness（官方称跑 Fable/Astra 比其他 harness 省 39%）、云端并行沙箱、DeepWiki 代码库索引、生产力估算器 |
| **转手卖什么** | 第三方前沿模型 token（OpenAI/Claude/Gemini/xAI），超额明码「按 API 价」，占收入比例未公开 |
| **抽掉 AI 还剩什么** | 几乎不剩：一个 VSCode 分支 IDE、FedRAMP 流程、350+ 份企业合同 |
| **换掉它要付什么** | 很低：DeepWiki 索引可重建、Slack/Jira/GitHub 集成是标准件；团队普遍同时跑多个 agent |
| **上游原生做了会怎样** | 已经在做：Claude Code 与 Codex 就是同一件事，而 SWE-2 的底座是 Moonshot 的开源 Kimi K3 |

**不可替代性：弱。** 产品本体是上游模型的壳——它自己最强的模型是在别人的开源底座上做 RL 后训练（SWE-2 基于 2.8T 参数的 Kimi K3）`[官方]`，而最硬的那条基准 Terminal-Bench 4 上它只有 **27.3%**，对 Fable 5.1 的 55.8%、GPT-6 Astra 的 57.9% `[官方自己公布的表]`。切换成本以周计，企业同时跑两三家 agent 是常态。它真正难复制的是企业分发（350+ 合同、FedRAMP、AWS/能源部），但那是买来的和攒来的资质，不是产品属性。48x 收入定价的，是它能不能在上游原生化之前把这层资质变成转换成本——目前还没有证据说它能。

## 3. 北极星指标

- **North Star**：**每月交付的「生产性工程小时」**（productive engineering hours）。这不是我推断的——官方 2026-06-04 的两篇博客把它写成了明确的内部指标选择，原话是行业要「从最大化用量指标转向最大化结果」，并为此造了估算器、拿企业用户的人工估时校准（r_log = 0.74）、再把它写进 $10M 担保 `[官方]`。
- **为什么是它**：它领先于收入两步。一个企业把 Devin 从 20 席扩到 200 席之前，先发生的是「这个月它替我们干掉了多少工程小时」变得可信；而这个数掉下来，续费和扩席会在下一个季度才反映到收入里。
- **配套指标**：① **PR 合并率**（34% → 67%，官方 2025-11）—— 直接代表「白跑的会话」比例；② **月度 ACU 用量**（E 轮博客里唯一放出的那张图就是 2025-08 到 2026-08 的月度 ACU 曲线，官方没给刻度）`[官方]`；③ **企业客户数与席位扩张**（350+ 起步，之后未更新）`[未公开]`。
- 注意：前两个官方都只在节点性博客里给过一次，没有持续披露。

## 4. AI 在业务中的作用

| 层次 | 它的情况 |
|---|---|
| **AI = 产品本身** | 是，彻底是。抽掉模型，剩下一个 VSCode 分支和几份企业合同 |
| **AI = 效率杠杆** | 是，而且被它当成营销资产：媒体口径称它自己约 **89% 的代码由 Devin 写** `[媒体]`；三四百人做到 $1B 年化就是这条杠杆的结果 |
| **AI = 营销标签** | 有，在「AI 软件工程师」这个词上。官方自己 2025-11 的绩效评估说得比批评者克制也更准：**理解代码库是资深水平、执行是初级水平**。独立评测给过更难听的数字：2024 年发布版本在 20 个任务里只完成 3 个 `[第三方，测的是两年前的版本]`；2026-06 一篇论文称跨 Copilot/Devin/Cursor/Claude 的 agent 提交被拒率 **46.41%**（作者本人说不能全算 agent 的错）`[第三方]`；Gartner 上 2026-06 的用户评论打 4.0，吐槽它「会绕圈、会基于错误假设跑很久」`[第三方]` |

**自研还是调 API：两条都走，但底座不是自己的。** 付费计划里直接给 OpenAI、Claude、Gemini、xAI 和开源模型的完整可用性 `[官方定价页]`；同时自己训 SWE 系列，最新的 **SWE-2（2026-09-10）是在 Moonshot 的 Kimi K3（2.8T 参数、已经做过大量 agentic RL）上做后训练**，FrontierCode 1.1 Main 拿到 50.0%（Fable 5.1 是 50.9%）而便宜 64%；但 Terminal-Bench 4 只有 27.3%，对 Fable 5.1 的 55.8% `[全部官方]`。SWE-2 不开 API、不给第三方路由、没有 model card —— 只在 Devin 里用。TechCrunch 把这件事的动机说得很直白：**训自己的模型是为了减少对 OpenAI 和 Anthropic 的依赖、往盈亏平衡挪一点** `[媒体]`。

**上游升级是利好还是威胁：两头都是。** 利好那头它自己写过——2026-07-13 的《Making Fable Cheaper Than Opus》论证的是 harness 比模型单价更决定实际成本，所以新模型一出来它就能蹭到 `[官方]`。威胁那头不需要论证：Claude Code 和 Codex 做的就是同一件事，而且不需要再谈一次采购。

## 5. 增长引擎

主引擎换过一次，这是它最值得学的地方。

1. **2024-12 到 2025-04：销售驱动，几乎没跑起来。** $500/月起、先谈合同，九个月做到约 $1M 年化。
2. **2025-04 之后：自助驱动。** 入门价 $20，Sacra 的记录是「主要靠个人开发者和小团队自助采用」把 ARR 推到 $73M `[第三方]`。
3. **2025-07 之后：买来的企业引擎。** Windsurf 的 350+ 企业客户、几十万日活、一支 GTM 团队，加上企业 ARR 当时就在季度翻倍 `[官方]`。此后的主引擎是企业直销 + 渠道：Cognizant、LTM（服务 260 家客户，含 26 家 Fortune 500 与全球前五大银行）`[官方]`、AWS 多年战略合作 `[官方]`、FedRAMP High In-Process 打开联邦口子 `[官方]`、能源部 Genesis Mission MOU `[官方]`、以及 2026 年新开的东京、新加坡、伦敦、圣保罗、马德里、华盛顿办公室 `[官方]`。
4. **辅助引擎：担保。** $10M 封顶的生产力担保是一个销售工具——把「说不清 ROI」这个采购阻力，变成供应商承担的风险。
5. **辅助引擎：小团队收并购。** TierZero（运维自动化）、The Interaction Company / Poke、Dioxus，全在 2026-07 到 09 三个月内 `[官方]`。买的是人和产品面，不是收入。

没有看到任何靠社区或病毒传播的证据；DeepWiki 免费开放更像内容型获客（给任意开源仓库生成文档），规模未公开。

## 6. 风险与争议

1. **收入质量：这 10 亿里有多少是自己长出来的，从来没拆过。** 最后一次外部可验证的拆分是 2025 年中的 $73M（Devin）+ $82M（Windsurf）。此后官方只给合并的「annualized revenue run rate」，而 TechCrunch 明确指出**公司没有解释这个数怎么算的**，通常口径是某一个月乘 12 `[媒体]`。一个按月乘 12 的数，在用量型产品上对单月波动极其敏感。
2. **单位经济与烧钱：收入进来多少，机器拿走多少。** 年化 $1B 对今年可能 $800M 的现金消耗 `[媒体引 The Information]`，其中租 NVIDIA 集群一项就是「每年数亿美元」。它自研模型省 64% 推理费是在往回抠毛利，但底座是别人的开源权重——**成本结构的主动权仍不在自己手里**。
3. **上游与同行同时压过来。** 上游：Claude Code、Codex 原生做同一件事。同行：Cursor 在 2026-04 以 **$60B 卖给 SpaceX**，当时年化已过 $2B，投资人对 TechCrunch 的说法是它卖身主因是**算力严重受限**；TechCrunch 春季报道 Cursor 年底年化将过 $6B，高于 Cognition 自己 $4–5B 的预期 `[全部媒体]`。更微妙的是，a16z 刚从 Cursor 的出售里赚到钱，转头领投它的竞争对手——这既是背书，也说明这个市场在投资人眼里不是赢家通吃。顺带一个风险点没人提：Cursor 被算力卡死的那件事，Cognition 一样可能遇上。
4. **可靠性与验收的双重自证问题。** 官方自己的 PR 合并率 67% 意味着**三分之一的会话白跑**（而客户为跑掉的用量付了钱）；最硬的 Terminal-Bench 4 只有 27.3%。更要紧的是 ROI 的证据链：「交付了多少生产性工程小时」是**它自家的 agent 估的自家价值**，r_log 0.74 在聚合上够用、单次预测不准（官方承认），而 $10M 担保的触发判定用的也是同一个估算器。让卖方给自己开发票，哪怕方法论公开，也不是审计。
5. **估值对预期的依赖。** 48x 收入对应的是年底 $4–5B 的口径。这意味着它必须在未来一个季度再翻两倍以上；而第 1 条说明我们连现在这 10 亿的构成都看不清。

## 7. 给我的启发

1. **在用量型 AI 产品里，定价结构的一次改动可能比模型升级更能改变曲线。** $500/月九个月做到 $1M，$20 起九个月做到 $7,300 万。看一家 agent 公司时，先问「它上一次改价是什么时候、改完曲线怎么走」，这比问「它用的什么模型」信息量大得多。
2. **被巨头 acquihire 掏空的公司，残骸是这一轮最便宜的分发资产。** Google 付约 $24 亿拿走人和授权，留下的 $82M ARR、350 份企业合同和一个被用户喜欢的 IDE，被一家当时年化 $73M 的公司以未披露的价格整锅端走，14 个月后它年化 $1B。看到「某公司被 acquihire」的新闻时，该问的下一个问题是「剩下的客户关系归谁了」。
3. **「有自研模型」不等于「有底座」，这两件事的护城河价值差一个数量级。** SWE-2 的全部价值是同分便宜 64%——那是成本结构的胜利，不是能力的胜利，而且它站在别人的开源权重上。判断一家 agent 公司时，该问的不是「它有没有自己的模型」，而是「它的毛利靠什么往回抠，以及这件事的主动权在谁手里」。
