**它凭什么长这么快。** 三件事，排第一的不是模型。

**第一件是它卖的东西和上游不是同一件东西。** 2025 年 3 月那个时点，ChatGPT 和 Claude 给的是**答案**，Manus 给的是**跑完的活**：它开一台云端虚拟机，自己装环境、自己开浏览器、自己写文件，几十分钟后交回一个能直接用的 PPT、网站、表格或爬完的数据。官方公布的两个用量数把这件事的规模说清楚了——上线到 2025-12 共处理 **147 万亿 token**、创建 **8,000 万台虚拟电脑** `[官方]`。对一个没有技术能力的人来说，这是他第一次能让 AI「动手」而不只是「说话」；需求侧的证据是上线一周 demo 过百万播放、等待名单超 **200 万人** `[第三方 Sacra]`，邀请码在二手市场被炒到 **5 万–10 万元人民币** `[第三方，维基引媒体]`。

**第二件是曲线折向上的那一次来自产品迭代节奏，不是来自融资。** 官方在 $100M ARR 的博客里把折点标得很明确：**自 2025-10-16 的 Manus 1.5 发布之后，月环比增长持续 >20%** `[官方]`。而 1.5 到 2.0（2026-09-28）这一年里，它上线的东西几乎全是「把一次性任务变成常驻流程」：连接器（Slack / Notion / Gmail / Google Drive / Shopify / Zoom / HubSpot / Similarweb）、Projects（会从每次任务里学）、Project Skills（把团队经验变成可复用资产）、Scheduled Tasks 2.0 → Automations（邮件、广告数据、日历、Slack 消息都能当触发器）。**从「我让它干一件事」到「它每天替我干」，这是客单价和留存一起上台阶的地方。**

**第三件是它把自己从中国搬了出去。** 2025 年中，总部从武汉/北京迁至新加坡，约 **120 名中国员工里只有 40 人随迁，其余裁撤**，同时**屏蔽中国大陆访问** `[第三方，维基引媒体]`。这一刀砍掉了国内市场，换来的是能正常调用 Anthropic/OpenAI 的模型、能收美元订阅、能拿 Benchmark 的钱——Sacra 口径里它收入最高的三个市场是**日本、中东、美国** `[第三方]`。2025-05 美国财政部按「对外投资安全计划」审查 Benchmark 这笔投资时，Benchmark 律师给出的「不在管辖范围内」的理由之一是：**Manus 不自己训练基础模型**，且蝴蝶效应注册在开曼 `[第三方，维基引媒体]`。这句为了过审说的话，恰好是本篇第 2 节要用的最硬的证据。

## 1. 核心产品

**卖什么。** 一句话：**一台会自己干活的云端电脑，按「积分」计量卖给非技术人员**。

用户在对话框里写一句话（「把这 200 家公司的融资情况整理成一份带图的 PPT」），Manus 在云端起一个沙箱环境，自己规划步骤、自己调工具（浏览器、终端、代码、第三方 API）、自己产出文件，中途可以被看、被打断、被分叉（Branch），跑完给一个可下载/可发布的交付物。官方把这台沙箱直接叫 **Cloud Computer**，2026-04-30 起还能买「常驻不关机」的版本（跑游戏服务器、跑长期自动化）`[官方]`。

**Manus 2.0（2026-09-28）之后的形态**是四块 `[官方]`：

- **Cascade** —— 自研的 agent harness（任务编排与能力按需加载）。官方给了一组对照数：同一配置下比上一代**少用 23.2% token、任务时间少 28.2%、运行成本低 32%**。
- **Manus Studio** —— 桌面端工作台，文档/表格/PDF/幻灯片/网站/代码/游戏/视频都在里面；含 Video Editor（时间线剪 AI 生成的片段）、Game Dev（浏览器可玩的游戏，多人靠 Cloud Computer）、Remote Control（在你自己电脑上、用你授权的文件和浏览器干活，手机上能看实时画面）。
- **Automations** —— 由连接服务的事件触发（新邮件、广告数据变化、日历、Slack、Notion），一句话描述触发条件和后续动作。
- **Cue** —— 独立的个人 agent App：**每个 agent 有自己的邮箱、电话号码、钱包和电脑**，能在预算内自己花钱，还能和别人的 agent 拉群协作。早期邀请制免费，电话号码单独订阅 `[官方]`。

**Before / After。**

| | 原来 | 现在 |
|---|---|---|
| 做一份带调研的提案/PPT | 自己查 2–4 小时 + 排版 1 小时；或者外包，离岸按小时 $15–30 | 一句话，一次任务约 200–900 积分 `[第三方 Sacra]`，按现价约 **$1–4.5** |
| 把重复的办公流程自动化 | 要么找人用 Zapier/n8n 搭（懂流程的人往往不懂工具），要么雇实习生每天手工做 | 描述触发器和动作，Automations 常驻跑 |
| 想做个小工具/小网站 | 招外包、或者学编程 | 官方的客户故事里，86 岁的非程序员用 5 个月做出一个能用的语言学习 Web App `[官方]` |
| 让 AI「动手」 | ChatGPT/Claude 给答案，落地那一步仍是人 | 云沙箱里自己装环境、自己开浏览器、自己提交 |

替代的是**人自己的时间**，和**实习生/外包的时间**——不是某个在位软件。这决定了它的定价参照物（见第 2 节），也决定了它为什么必须做消费级定价。

## 2. 商业模式

- **收费对象**：**个人自己刷卡为主**（prosumer），加一条小团队席位；企业侧只有 Team 版、微软 Agent 365 合作与一个在做的 enterprise SDK `[第三方 Sacra]`，官方从不披露 B2B 收入占比。这是本档 48 家里极少数**主要由个人掏钱**的生意。
- **定价结构**（2026-10-13 取自官方帮助中心与 /team 页）`[官方]`：

| 档 | 价格 | 积分/配额 |
|---|---|---|
| Free | $0 | 每日刷新 300 积分（二手口径：每月上限 1,500，且只能用 Manus 1.6 lite `[媒体]`）；1 个并发任务、2 个定时自动化 |
| Pro（低档） | **$20/月起**，年付 **-17%** | 每月 **4,000 积分**起；20 个并发任务、20 个自动化 |
| Pro（高档） | **$40/月起**，含 **7 天免费试用**，年付 -17% | 每月 **8,000 积分**起 |
| Team | **$20/席/月** 或 **$200/席/年** | 基础 **4,000 积分/席/月**，积分团队共用；管理员可买加购积分并开自动续费 |
| SSO | 30 席以上免费；30 席以下 **$150 一次性** | —— |
| Manus Flex（2026-09-29） | 自带推理 API key（OpenRouter / Fireworks / Modal） | 模型费由你的供应商直接向你收；Manus 侧的其他服务与基础设施**仍然消耗积分** `[官方]` |

**这张表里藏着本篇第二个最该注意的事实：单价腰斩了。** Sacra 记录的上一代定价是 **Starter $39 / 3,900 积分、Pro $199 / 19,900 积分、Team $39/席且 5 席起** `[第三方 Sacra]`——每积分约 **$0.010**；现价 $20 / 4,000 积分 = 每积分 **$0.005**。**同样的活，用户付的钱少了一半**。同期官方自己公布 Cascade 把运行成本降了 32% `[官方]`。成本降 32%、售价降 50%，差额去哪了，官方没说；但「按积分卖 agent 工时」的生意，正在用价格换用量，这件事从账面上看得见。

- **单位经济**：**毛利率、推理成本占比、留存、付费用户数，全部未公开**。能确定的只有成本结构的形状：Sacra 把成本拆为「规划用的 LLM token + 执行用的虚拟机时长 + 第三方 API 调用」，并指出**额外用户带来的边际成本主要是第三方模型 API 调用** `[第三方]`。官方在周年信里把下一阶段的三个前提之一写成「**在那个规模上把成本维持在可行范围**」`[官方]`——这是一家公司愿意公开承认成本是约束时才会写的句子。
- **它从谁的预算里抢钱**：**个人可支配支出 + 实习生/外包的人力预算**，不是企业软件预算。好处是采购阻力为零（自己刷卡，20 美元）；坏处是天花板由「一个人每月愿意为省时间花多少钱」定，而且**和 ChatGPT Plus 的 $20 在同一个钱包格子里直接打架**。

## 3. 北极星指标

- **North Star（推断）**：**每天「被用户接受」的完成任务数**——不是任务发起数，也不是 ARR。依据有三条：① 官方唯一主动公布的两个用量数是「147 万亿 token」和「**8,000 万台虚拟电脑**」，后者几乎等价于任务数；② 2.0 的工程成绩全部按「每任务」口径报（每任务少 23.2% token、少 28.2% 时间、低 32% 成本）；③ 积分制意味着**收入 = 任务数 × 每任务积分 × 单价**，三项里只有任务数是领先指标。
- **为什么是它**：积分订阅的续费决策发生在「上个月我的积分是不是换来了真东西」。任务完成率一掉，积分消耗先虚高（重试），然后续费塌。它比 ARR 早一个计费周期。
- **配套指标（推断）**：① **常驻自动化数/用户**——Automations 和 Projects 是把一次性用户变成留存用户的那个开关，官方整年的产品投入都压在这；② **每任务成本**（官方自己按这个口径报 Cascade 的成绩）；③ **积分加购率**——愿意在包月之外补钱买积分的用户比例，是付费意愿最硬的证据。
- 以上全部为**推断**：官方从未披露 MAU、付费用户数、留存或任何一个北极星口径。

## 4. AI 在业务中的作用

| 层次 | 该公司的情况 |
|---|---|
| **AI = 产品本身** | **是，且是纯的**。没有 LLM，产品不存在——Manus 卖的就是「模型会自己动手」这件事。 |
| **AI = 效率杠杆** | **是，而且是本档最极端的样本之一**：105 人做 $100M ARR（官方 ÷ 官方），人均 $95.2 万。它的成本结构里人头不是主项，推理和沙箱才是。 |
| **AI = 营销标签** | **几乎没有虚的成分**，但有**口径上的虚**：$90M（2025-08）是「含 Monica、按前 30 天年化」，$100M（2025-12）是「最严格的订阅口径」，$125M 是「含用量与其他收入」，$450–500M（2026-06）是第三方估算与媒体转述。四个数来自四种算法。SCMP 引业内分析师的话说得直白：ARR 没有标准算法，**容易被初创公司滥用** `[媒体]`。 |

**自研还是调 API。** **全部调 API**，而且有权威旁证：2025-05 美国财政部审查 Benchmark 投资时，「**Manus 不训练自己的基础模型**」被当作该投资不属管辖范围的依据之一 `[第三方，维基引媒体]`。技术起底材料记其早期以 **Claude 3.5 Sonnet 为核心推理引擎、辅以微调过的通义千问（Qwen）** `[第三方，首席科学家公开，约 2025 年中，已过时]`。2026-09-29 的 Manus Flex 把这件事制度化：接入 OpenRouter、Fireworks、Modal 三家推理伙伴，**用户自己设主模型和推理强度，模型费由供应商直接向用户收** `[官方]`。

**模型层依赖风险：高，而且是双向的。** 一边是商业依赖——Sacra 明确点出「**广泛依赖第三方模型，主要是 Anthropic 的 Claude**」，并提示涨价、断供、上游自做 agent 三重风险 `[第三方]`；Anthropic 2025 年起限制中国总部公司的模型访问 `[第三方 Sacra]`，这是它搬去新加坡的现实原因之一。另一边是地缘依赖：2026-06 Anthropic 向美国参议员和白宫指控与 Qwen 实验室相关的操作用近 2.5 万个虚假账号跑了约 2,900 万次 Claude 交互 `[媒体，彭博]`——Manus 身处「用美国模型的中资背景公司」这个夹层里，任何一次收紧都直接打在它的成本和可用性上。

**基础模型升级，是利好还是威胁？** **短期利好、长期威胁，而且它自己选了后者更难的那条路。** 利好很实在：模型越强，harness 能放手的边界越大，官方周年信把这一年的进展直接归功于「基础模型令人窒息的进步速度」`[官方]`。威胁更结构性：Manus 的全部价值在「模型和工具之间那一层」，而这一层正是所有上游都在往产品里收的东西——ChatGPT 的 Agent 模式已经**包含在约 $20/月的订阅里** `[第三方评测]`，和 Manus 的 Pro 低档同价；开源的 OpenClaw 可以自己部署，零边际成本 `[第三方评测]`。

## 6. 风险与争议

**一、收入质量：四种口径、四个月静默、以及一次「所有权真空期的增长」。** $90M（含 Monica、按前 30 天年化）、$100M ARR（最严口径订阅）、$125M（含用量）、$450–500M（第三方估/媒体转述）——**这四个数不能连成一条曲线**。更值得警惕的是时间分布：最后一个公开数是 2026-06，而 2026-10-08 的 $500M+ 融资新闻里，媒体引用的还是 6 月那个数。一家在 2025-12 愿意专门发博客宣布 ARR 的公司，**在收入翻 5 倍之后连续 4 个月不报数**，这本身是一个信号。另外，那 5 倍恰好发生在 Meta 收购已宣布、中国监管调查中、所有权悬空的那半年里——CNBC 在 2026-01-21 就报道**部分现有客户因为 Meta 这笔交易而转投别家** `[媒体]`，而同期收入据称翻了几倍，两件事至少有一件没被完整讲出来。

**二、看空视角：这是一门「上游顺手就能做掉」的生意，而且价格已经在被压。** 它的护城河是 harness 工程效率（32% 成本优势），而 ChatGPT 的 Agent 模式已经免费装进同价订阅、Genspark Claw 给每个用户配专属云电脑、OpenClaw 可自部署 `[第三方评测]`。证据不在分析里，在价目表上：**每积分单价从 $0.010 降到 $0.005**。而消费级订阅的留存本来就脆——评测里反复出现的两类投诉是「**积分消耗不可预测、没有超支预警**」和「**任务自称完成但交付物不可用**」`[第三方评测/应用商店评论]`。这两件事一起发生时，用户流失不需要竞品出现。

**三、地缘与所有权风险是这家公司的头号风险，且已经兑现过一次。** 时间线：2025 年中迁新加坡、120 名中国员工只留 40 人、屏蔽大陆访问 `[第三方]` → 2025-05 美国财政部审查 Benchmark 的投资 `[第三方]` → 2025-12 Meta 宣布收购，报价约 $2B（一说 $2–3B）`[第三方/媒体]` → 2026-01 中国商务部启动评估性调查，部分高管被限制出境 `[第三方，维基引媒体]` → **2026-04-27 国家发改委否决并要求撤回** `[第三方/媒体]` → 2026-06-15 Meta 宣布切断关系 `[第三方]` → 2026-08-11 官方《致用户的一封信》、**部分用户数据需要备份与恢复、访问临时中断** `[官方]` → 2026-09-01 恢复独立运营 `[官方]` → 2026-10-08 超 $500M 新一轮，博裕与 IDG 领投 `[官方]`。**对一家卖给企业的 agent 公司，「我们的数据在谁手里」被公开演示过一遍，是实打实的销售阻力**；路透口径里它还在考虑香港 IPO `[媒体]`。

**四、估值倍数在反向说话。** 收入 5x、倍数从 20x 压到 8x `[媒体口径，估值未经官方确认]`。市场不是不认它的收入，是给这些收入打了折——消费级订阅、模型全外购、地缘风险、所有权刚出过事，四项各打一刀。对照 Cognition 的 48x，**同为「agent 公司」，收入的质量差异被定价到了 6 倍**。

**五、投资人结构换了血。** 新一轮由**博裕资本与 IDG 领投**，腾讯、HSG、真格跟投 `[官方]`；Benchmark 还在不在股东名单里、Benchmark 的 Chetan Puttagunta 是否还在董事会，官方没说。一家刚被监管按回中国资本怀抱的公司，接下来能不能继续以「新加坡公司」身份调美国模型、卖美国市场，是它整个商业模式的前提条件，而这个前提不由它决定。

## 7. 给我的启发

**一、「增速」和「收入质量」是两个独立维度，而市场只给后者付倍数。** 本篇最该记住的不是 5x，是**收入翻 5 倍而估值倍数从 20x 掉到 8x**。同周看过的 Cognition 是 48x。差别不在增速，在收入背后的四件事：谁掏钱（企业编制 vs 个人钱包）、换掉你要付什么（迁移成本 vs 周级可走）、模型是谁的（自研 SWE-2 vs 全外购）、你受谁管（FedRAMP 流程 vs 发改委）。**看一家 AI 公司，先看它的倍数在往哪个方向走，再去听它的增速故事。**

**二、当一家公司推出「自带 API key」时，它在替你回答护城河问题。** Manus Flex 的产品逻辑是：模型费你自己付给供应商，Manus 只收 harness 和基础设施的钱。这等于公司自己划出了可替代的部分和不可替代的部分。**凡是上游能被用户自己换掉的生意，护城河的上限就是那层中间件的工程效率**——Manus 公布的数字是 32% 成本优势。32% 是真的，但 32% 不是护城河。下次看到「我们支持多模型/自带 key」，先把它当成一份自我鉴定来读。

**三、「成本降了 32%、售价降了 50%」比任何竞争分析都准。** 不必争论 ChatGPT Agent 会不会杀死 Manus——把它两代价目表并排放，每积分 $0.010 → $0.005 已经把答案写在那了。**定价是竞争压力唯一不会说谎的地方**：一家护城河在变强的公司会涨价（见 Flow Engineering 把 $400/席 卖到 $1,800–3,600/席），一家护城河在变薄的公司会用降价换用量。看公司时，把历史定价页翻出来按时间排一遍，比读十篇融资稿有用。
