**它凭什么长这么快 —— 因为它卖的是一个可以直接写进财务模型的数字：把你的前沿模型 API 账单砍掉一半，而且模型的权重归你。**

这家公司全部公开案例的结论都是同一句话的不同写法。Harvey 的 Review Table 自有模型，**每格平均成本比 Claude Sonnet 5 低 54.8%**，同时答案分 **0.903 对 Fable 5 的 0.867、GPT-5.6-Sol 的 0.857** —— 更便宜**且**更准。Clay 的 Claygent 路由器在**线上 A/B** 里比全量走 GPT-5.6 Sol **省 47%**，质量守住护栏指标。它自己放出来的 Shift-1 路由器，在 Codex 场景下比全量走 GPT-6 Astra **省 55%**，SWE-bench Verified 精度不降。Cognition 的 Windsurf 实时查错模型比前沿替代**快 10 倍**（Opus 4.6 是唯一达标的模型，但太慢太贵，没法每次敲键都调）。

把这些百分比换成绝对值就是它的报价依据：**一家一年在前沿 API 上花 $2,000 万的公司，砍一半就是一年 $1,000 万。** 这个数量级足够大到让任何 CFO 不需要被说服 —— 这就是它能在不到 6 个月里从 0 做到 $1,280 万年化、12 个月做到 7.8 倍的全部原因。

但增速真正折向上的那一刻不是哪次模型发布，是 **2026-08-25 AC2（Agent Cloud）上线**。在那之前，这门生意的形态是「三个前 OpenAI 的 RL 基建工程师带队驻场给你训一个模型」—— 是项目制、是人力瓶颈、收入是服务费。AC2 把训练、服务、持续改进打包成一个带 CLI 和 SDK 的云之后，收入从「卖研究员的时间」变成「卖 token」，月增速从 16% 跳到 26%，而官方愿意拿出来说的唯一一个结构性指标也正是 **「40% 的客户同时用训练和推理」** —— 训练是一次性的项目，推理才是复利。这个 40% 就是这家公司的真实估值基础。

还有一条必须放在最前面：**它最强的那个卖点，技术含量是零。** 它自己的文章《Moats Need Models》里写明两条非技术理由 —— 前沿实验室正在往应用层走，有些客户已经在和自己的模型供应商竞争；以及有些新发布的模型**不提供零数据留存**，企业不敢把生产 trace 交出去。换句话说，它卖的一部分是**供应商中立性**。这一条，上游原生怎么做都做不出来。

## 1. 核心产品

**卖的是「把别人的开源权重，改造成只属于你的那个模型，然后替你跑起来」这整条流水线。**

产品名叫 **AC2（Applied Compute Agent Cloud）**，2026-08-25 上线，四块：

- **Router** —— 每个请求派给最合适的模型。它给 Clay 训的 AC-001 就是这个：基座 Qwen 3.6 35B A3B，用 **GRPO** 训，输入是查询 + 候选模型配置，输出是查询类别 + 每个候选的预测质量分，再按「预测质量 − λ × 该类平均成本」选效用最高的那个。调 λ 就能在质量和成本之间滑动，并用「每类质量下限」防止一类省出来的钱被另一类的质量损失吃掉 `[官方]`。
- **Train** —— 面向会用工具的 agent 的后训练，带奖励调参和 rollout 可观测性。自研技术主张是**全异步 RL**（数据生成和权重更新同时跑，而不是串行）和**自蒸馏**（不需要教师模型）。
- **Serve** —— 生产推理，按吞吐/延迟/并发调部署拓扑。
- **Improve** —— 用生产 trace 继续训、online RL（拿收到的真实 prompt 周期性微调权重）、发布版本 A/B。

外加一个自家的研究 agent **Ari**（2026-08-12），以及一个会总结「这次训练到底学到了什么技能」的内置助手。认证是 **SOC 2 + ISO 42001**，可选 serverless 或客户 VPC 部署 `[官方]`。

**Before / After 的差异不在产品，在组织。**

**Before —— 企业有两条路，都难走：**
- **路 A：每个请求都调前沿 API。** 贵（Cognition 的例子：Opus 4.6 是唯一达标的，但贵到没法每次敲键都调）、慢、不差异化（所有人拿的是同一份权重）、而且要把生产 trace 交给一个可能在应用层跟你竞争的供应商。
- **路 B：自己建后训练团队。** 要同时搞定训练编排、沙箱、自动评分器、异步调度、服务部署 —— 这是一整套基础设施，而懂这套的人在 2026 年是全球最稀缺的工种之一。按旧金山行情，一名前沿实验室级别的 RL 基建工程师总包常在 **$50 万–$100 万+**，一个 5 人小队一年 **$300 万–$500 万**，而且**第一个模型进生产之前还要先花 6–12 个月建基础设施** `[估算，依据：公开招聘行情 + 官方自述的「基础设施 + 评测」两道门槛]`。

**After —— 变成一个采购项目。** AC 派驻场研究员进来，客户出领域专家和**评测集**（官方的说法最关键：「评测，而不是数据量，才是模型真正的规格说明书」），AC 在 AC2 上搭数据流水线、任务生成、基于 oracle 的 ground truth，然后训。Harvey 那个案例写得最清楚：**基座 GLM 5.2 直接放进 Harvey 生产环境里的那套单轮语义检索 harness 训练，检索架构一行不改，用的是从开源法律文书合成的数据集，不用任何客户数据** `[官方]`。

最后一步是这家公司和所有同类最大的差别：**权重归客户**。官网主标语就是 **「Your data. Your model. Your edge.」**

## 2. 商业模式

- **收费对象**：**买方几乎全是技术组织，但掏的是两个不同的口袋。** 一个是**推理账单**（原本付给 OpenAI / Anthropic 的那笔），一个是**没招成的那支 ML 团队的编制**。已披露的 13 家客户里，一半是 AI 公司（Mercor、Harvey、Cognition、Clay、Decagon、Semgrep），一半是把 AI 装进既有业务的大公司（Microsoft、Shopify、DoorDash、NVIDIA、Handshake）。前者买的是毛利率，后者买的是一个做不动的项目。
- **定价结构**：**官方未公开，而且是刻意不公开。** `/pricing` 返回 404，文档让你去找对接人。按 The Information 的描述是 **顾问服务费 + 按算力计费** 的混合 `[媒体]`。官网另外给了两种合作形态：**Embedded** 和 **Managed** `[官方]` —— 这两个词本身就说明交付里有人力。全自助报价不存在，每一单都过销售。
- **单位经济**：**毛利率、推理成本占收入比、训练收入与推理收入的拆分，全部未公开。** 能推的只有间接证据，而三条都指向「这不是 SaaS 毛利」：①累计融 $511.76M 只换回 $100M ARR（每 $1 股权 $0.20），而 CEO 说新钱主要买芯片；②每天 1 万亿 token 的服务量，按前沿模型级别的对外单价折算量级与它的全年收入同阶 `[估算，口径不明：这 1 万亿里有多少是训练 rollout、多少是对外计费流量，官方没说，所以这个推算只能当量级参考，不能当收入结构]`；③Cognition 那个案例的**推理是跑在 Cerebras 上的**，不是跑在它自己的云上 —— 连算力都有一部分是转手。
- **它从谁的预算里抢钱**：**主抢软件/云预算（前沿 API 账单），次抢人力预算（ML 团队编制）。** 这个顺序对估值是坏消息。抢人力预算的公司天花板是「一份年薪」，抢 API 账单的公司天花板是**「被替代那笔账单的一半」**，而那笔账单的单价**正在以每年数量级的速度下降**。它的收入锚在一个会自己缩水的分母上 —— 这是全篇最该记住的一句话。

## 3. 北极星指标

- **North Star（推断）**：**「客户从训练转向推理的转化率」** —— 官方唯一拿出来公布的结构性比例就是 **「40% 的客户同时使用训练和推理」** `[官方]`。
- **为什么是它**：这家公司的两种收入性质完全不同。**训练是项目制**（一次性、吃驻场研究员的工时、不可复利、本质是咨询），**推理是云**（按 token 计、随客户业务增长自己涨、才配得上 32.5x 倍数）。所以真正决定它是「$1 亿的咨询公司」还是「$32 亿的云」的，不是 ARR，是训练项目**转化成常驻推理流量的比例**。这个比例领先于收入变化：先有训练项目、再有模型上线、再有推理账单，中间隔一个季度。40% 这个数如果能往 70% 走，32.5x 就不算贵；如果掉到 20%，这就是一家被当成云定价的咨询公司。
- **配套指标**：①**每天推理 token 数**（当前 1 万亿+/天，`[官方]`）—— 推理侧真实渗透的直接计数；②**训练任务数**（AC2 自 2026-07 起 1,700+ 次 `[官方]`）—— 平台自助化程度，这个数除以客户数再除以月份，就能反推一个客户每月自己能发起几次训练，是「平台」与「外包」的分水岭；③**企业客户数**（自上轮翻倍以上，绝对值未公开 `[官方]`）。
- 留存、净收入留存（NDR）、按客户的收入集中度：**全部未公开**。对一家 32.5x 倍数的公司，缺 NDR 是最贵的一处缺失。

## 4. AI 在业务中的作用

| 层次 | 该公司的情况 |
|---|---|
| **AI = 产品本身** | **是，而且是少数「产品就是训练过程本身」的一类。** 它交付的不是一个会调 AI 的软件，是一份权重文件和一条能持续更新它的流水线。抽掉 AI 这家公司不存在 —— 它连一个可以不带 AI 存在的产品形态都没有。 |
| **AI = 效率杠杆** | **是，而且是可验证的自用。** 自研研究 agent **Ari**（2026-08-12）带奖励作弊检测；自己的路由器 **Shift-1** 先在内部用（**11.8 万条内部编码 turn 的开发者反馈标注**），把自家工程师的 Codex 开销对 GPT-6 Astra 降 55%、Claude Code 开销对 Opus 5.5 降 24% `[官方]`。70 人做 $1 亿收入、85% 是研究工程，这个结构本身就是自用的结果。 |
| **AI = 营销标签** | **有一处名不副实，而且在最关键的位置：它一个基座模型都不自研。** 官网写「THE AI SUPERCLOUD FOR OPEN MODELS」「The Best AI is Built, Not Bought」，但「Built」指的是后训练，基座全部来自 Qwen / GLM / Kimi。另一处是「云」这个词：Cognition 案例的推理跑在 **Cerebras** 上，不在它自己的云上。第三处是 ARR 这个词本身 —— 把「顾问服务费 + 算力费」统称 ARR，是对 SaaS 读者的一次借词。 |

**用自研模型还是调 API？** **都不是，走的是第三条路：拿别人的开源权重做后训练。** 这是一个被低估的依赖结构 —— 它不依赖 OpenAI/Anthropic 的 API，但它**完全依赖开源权重的持续供给**，而当前最好用的那几个基座（Qwen、Kimi、GLM）都来自中国实验室。这条供应链一旦因政策、许可证变更或实验室战略转向而中断，它的全部产品线失去原料。这个风险比「调 API 被涨价」更难对冲，因为它没有第二供应商 —— 而公开报道里没有任何人把这一条当成风险在讨论。

**基础模型每次升级，是利好它还是威胁它？** **这是本篇最需要分清的一问，答案取决于升级的是哪个维度。**

- **前沿模型变更强 → 利好。** 它的三块业务（蒸馏、路由、后训练）都需要一个强教师/强上限。Shift-1 的本质就是「尽量不调最贵的那个，但在该调的时候调得准」—— 没有一个强的 Astra，路由器就没有可路由的上界。
- **前沿模型变更便宜 → 直接威胁，而且是它唯一的致命伤。** 它所有案例的价值都表述为「比前沿便宜 47%–55%」。前沿 API 价格每降一半，这个 47% 的绝对金额就减半，客户做这个项目的 ROI 就减半，而项目的交付成本（驻场研究员的工时）不会同步减半。
- **开源权重变更强 → 利好。** 原料升级，它的后训练起点更高。
- **上游把后训练做成自助产品 → 威胁，但打不穿一半。** 前沿实验室的 fine-tuning / RFT 产品已经存在；它们做不到的是让客户**不把生产 trace 交给自己**。

## 5. 增长引擎

**主引擎是「用客户的名字做技术营销」，而不是 PLG 或传统 SLG。**

证据链很清楚。它在 13 个月里发了 **36 篇**博客 `[官方]`，密度是每 11 天一篇，而且里面绝大多数是**带甲方署名的联合技术报告**：Harvey（2026-06-22、2026-08-14 两篇）、Mercor（2026-02-24）、DoorDash（2026-02-17）、Cognition（2026-05-11）、turbopuffer（2026-09-04）、NVIDIA（2026-08-05）、Clay（2026-10-27）。Harvey 那篇的作者列表是 **Harvey 方 6 人 + Applied Compute 方 3 人** —— 这不是案例研究，是联合论文。

这套打法针对的是一个很具体的买家：**另一家 AI 公司的技术负责人**。这类人不看 ROI 幻灯片，只看奖励函数怎么设计、评测怎么做、λ 怎么选、staleness 怎么控。所以它把销售材料写成了研究报告 —— 而这也解释了为什么已披露客户里有一半本身就是 AI 公司，以及为什么 **Mercor、Harvey、Cognition、Clay、Decagon 五家都在本档已分析过**：它在 AI 创业公司这个小圈子里是靠口碑和同行背书传播的。

第二引擎是**创始人出身与投资人网络**。三位全是前 OpenAI 的 RL 基建工程师，这在 2026 年是一个直接可换算成信任的履历；Elad Gil 从 Pre-Seed 一路跟到 C 轮并领投，NVIDIA 既是投资人也是客户还合发技术博客（2026-08-05《Post-Training Collaboration with NVIDIA》）。有一条弱证据值得记：Chris Barber 做的一次非正式投票问「企业该去哪做后训练服务」，**Applied Compute 30 票、Trajectory 13 票、Prime Intellect 10 票、Thinking Machines 7 票、Fireworks 5 票** —— 但作者自己披露是 Applied Compute 和 Trajectory 的小额投资人，所以这只能当圈内声量的粗略读数，不是份额 `[媒体，有利益披露]`。

**不是引擎的**：自助增长。`/pricing` 404、文档让你找对接人、合作形态分 Embedded 和 Managed —— 这是一条彻底的销售驱动路径。70 人里 14 个在招岗位有 6 个是 GTM/运营，说明它自己也知道下一阶段的瓶颈在这。

## 6. 风险与争议

1. **「$100M ARR」这个数本身就是本篇最该打折的数字。** 官方只给了 **「topped $100M」** 这一个下界，没有绝对数、没有审计、也没有拆分 —— 而按 The Information 的描述，商业模式是**顾问服务费 + 按算力计费**的混合。把驻场研究员的服务费和 GPU 算力费一起叫 ARR，对一个按 32.5x 收入倍数定价的公司来说是实质性的口径问题：**服务费不会自己复利，算力费的毛利不是 SaaS 毛利。** 看空的第一句话就是：这可能是一家被当成云定价的咨询公司。

2. **客户集中度未披露，而名单顶上坐着 Microsoft。** 官方点名了 Microsoft、Shopify、DoorDash、NVIDIA，但没有任何一家的收入占比。Microsoft 同时是**客户**和**全世界最有能力自建这套东西的公司之一**；NVIDIA 同时是**投资人、客户、联合发文方** —— 这类关系里的收入，质量和一笔普通商业合同不是一回事。独立分析也直接问了这一条：这 $100M 里 Microsoft 和 DoorDash 占多少 `[媒体]`。

3. **它的收入锚在一个会自己缩水的分母上 —— 这是结构性的，不是执行问题。** 所有案例的价值都表述为「比前沿模型便宜 47%–55%」。前沿 API 的单价在过去两年里是以数量级速度下降的；每降一半，同一个项目给客户省下的绝对金额就减半，而交付成本（驻场研究员的工时）不减半。**它做的是一门套利生意，而套利空间由它的竞争对手定价。**

4. **切换成本是它自己主动放弃的，而且这是卖点不是失误。** 「Your data. Your model. Your edge.」意味着权重归客户、评测集在客户侧、harness 本来就是客户的。换掉它要付的只是重建训练流水线的研究人力。这个定位赢得了信任，但它同时意味着**续费完全取决于下一个项目值不值得做**，而不是取决于迁移有多痛。NDR 未公开，这里是最贵的一处信息缺失。

5. **原料供应商高度集中在中国实验室，而没人在谈这条。** 公开案例的基座是 GLM 5.2、Qwen 3.6 35B A3B、Qwen3.5-4B、Kimi K3 —— 全部来自中国。它不依赖 OpenAI 的 API，但它依赖中国开源权重的持续供给与许可证稳定。这条链上没有第二供应商。

6. **估值跑在证据前面，而且跑得很远。** 每股 $3.88 → $148.16，15 个月 38.2 倍；$3.25B 对一个「下界 $100M」的收入，32.5x。独立分析的判词是：这是在赌创始团队的执行力，**还不是在赌一条已被验证的护城河**，而且至今没有任何报道指出某个具体竞争对手因它而丢份额 `[媒体]`。另：C 轮在 Forge 上定价于 **2026-09-18**，公告在 **2026-11-02**，中间隔了 6 周，Forge 还自注「未找到独立公开信息确认 C-1/C-2 已完成交割」。

7. **赛道正在变挤，而且挤进来的都是同一批人。** Trajectory、Prime Intellect（本档已分析）、Thinking Machines、Fireworks、Veris、Osmosis 都在做「后训练即服务」。这是一个进入门槛高但不排他的市场 —— 门槛是「会做 RL 基建的人」，而那批人正在以每月数家新公司的速度各自创业。

## 7. 给我的启发

1. **「人均创收极高 + 资本效率极低」是一个组合信号，单看任何一个都会读错。** 这家公司人均 $143 万（传统 SaaS 的 6–9 倍），看着是极致高效的小团队；但每 $1 股权只换回 $0.20 ARR，是昨天那篇 HeyGen（$2.70）的十三分之一。两个数放一起只有一个解释：**钱花在 GPU 上，不在人头上。** 从今天起看 AI 公司，人均创收必须和「ARR ÷ 累计融资额」一起看 —— 前者告诉你组织效率，后者告诉你这门生意是软件还是重资产。只看前者会把一家 GPU 转售商读成一家软件公司。

2. **当一家公司的价值被表述为「比 X 便宜 N%」时，它的护城河上限就等于 X 的定价权，而 X 通常是它的竞争对手。** 这家公司所有案例的卖点都是「比前沿模型省 47%–55%」。这个表述读起来是优势，实际上是**把定价权交给了被替代的那一方**：前沿 API 每降价一半，它的客户 ROI 就腰斩一次，而它的交付成本不会同步下降。对照看 HeyGen 的「$2.3 对 $1,000」—— 那个价差有三个数量级，前沿降价一半也还剩三位数倍率。**看「比 X 便宜」的生意，要先问这个倍率是 1.5 倍还是 1000 倍，因为那决定了它还能活几轮降价。**

3. **最难被复制的那条优势，常常一点技术含量都没有。** 这家公司自己写明：客户不敢把生产 trace 交给一个正在往应用层走的供应商，而有些新模型还不提供零数据留存。**「我不和你竞争」这个身份，是 OpenAI 和 Anthropic 无论投入多少都做不出来的产品特性。** 这提示一个反直觉的选标方法：在一个上游巨头正在纵向整合的市场里，最稳的位置未必是技术最深的那家，而是**结构上不可能与客户竞争**的那家。但也要记住它的脆弱处 —— 这是一个法律与竞争格局的位置，不是资产；巨头换个策略（拆分、承诺不进入、给出合约级数据隔离），这条优势一夜之间就被平掉。
