# AI 创业公司研究

每天一家 AI 创业公司的深度分析，自动生成、自动归档、不重复。

**[→ 在线看板](https://wuyanbo9.github.io/ai-startup-study/)**

## 这是什么

一个跑在 [Claude Code routine](https://code.claude.com/docs/en/routines) 上的定时研究任务。每天早上它会：

1. 读 `reports/INDEX.md`，确认哪些公司已经写过
2. 检索近期的高增长榜单和融资新闻，挑一家**没写过**的公司
3. 用至少三个独立来源交叉验证，写成一篇结构固定的报告
4. 重新生成看板 `index.html`，提交并推送

选标的的规则只有一条最重要：**增长速度优先于规模**。一家 12 个月内 ARR 翻 5 倍、体量只有几千万美金的公司，排在体量十亿但同比只涨 40% 的公司前面。有名气不是入选理由。

## 每篇报告写什么

固定回答四个问题 —— 核心产品、商业模式、北极星指标、AI 在业务中的作用 —— 外加增长快照、增长引擎、风险与争议（必须包含看空视角）。

关键数字一律标注来源可信度：`[官方]` 公司自己公布、`[媒体]` 可信媒体报道、`[估算]` 推算并写明依据。查不到就写「未公开」，不允许编造。

## 看板

`index.html` 是自包含单文件，没有构建步骤也没有外部依赖，浏览器直接打开即可。统计块 + 赛道标签 + 每家一张卡片，点公司名就地展开报告全文，支持明暗模式。

改样式或抽取逻辑请改 `build_dashboard.py`，然后：

```bash
python3 build_dashboard.py
```

**刻意没有做跨公司的柱状图对比。** 这批数据口径并不统一 —— 有的报的是 GMV 而非 ARR，有的混用了「全年收入」与「某时点 ARR」，还有的只给了里程碑没给倍数。把它们并排画成柱子，会暗示一种数据本身并不支持的可比性。每家的口径以卡片内报告为准。
